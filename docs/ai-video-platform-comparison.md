# AI视频生成平台能力对比

> 可灵 (Kling) vs 海螺 (MiniMax Hailuo) - API版本能力对比

---

## 一、可灵AI (Kling) 能力

### 1.1 图生视频 (Image-to-Video)

| 能力项 | 支持情况 | 说明 |
|--------|----------|------|
| **首帧控制** | ✅ 支持 | `image` 参数指定首帧 |
| **尾帧控制** | ✅ 支持 | `tail_image` 参数指定尾帧 |
| **首尾帧模式** | ✅ 支持 | 同时使用首帧+尾帧 |
| **参考图模式** | ❓ 待验证 | 是否支持纯参考图不固定首帧 |
| **标准分辨率** | ✅ 768x768 | 使用标准参数时输出 |
| **原图尺寸跟随** | ✅ 支持 | 输出尺寸可跟随原图比例 |
| **时长选项** | 5s / 10s | 可选择5秒或10秒 |
| **运镜控制** | ✅ 支持 | 支持多种运镜指令 |

### 1.2 文生视频 (Text-to-Video)

| 能力项 | 支持情况 | 说明 |
|--------|----------|------|
| **纯文本生成** | ✅ 支持 | 仅用prompt生成视频 |
| **运镜控制** | ✅ 支持 | 支持运镜指令 |
| **负面提示词** | ✅ 支持 | 可指定不希望出现的内容 |

### 1.3 角色一致性方案

| 方案 | 效果 | 适用场景 |
|------|------|----------|
| **首尾帧模式** | ⭐⭐⭐⭐⭐ | 最佳一致性，可控制起止状态 |
| **首帧固定** | ⭐⭐⭐⭐ | 首帧角色固定，后续AI发挥 |
| **LoRA微调** | ⭐⭐⭐⭐⭐ | 可灵1.6支持，需上传多段视频训练 |

## 二、海螺AI (MiniMax Hailuo) 能力

### 2.1 图生视频 (Image-to-Video)

| 能力项 | 支持情况 | 说明 |
|--------|----------|------|
| **首帧控制** | ✅ 支持 | `first_frame_image` 参数 |
| **尾帧控制** | ✅ 支持 | `last_frame_image` 参数 |
| **首尾帧模式** | ✅ 支持 | 同时使用首帧+尾帧 |
| **参考图模式** | ❌ API不支持 | 网页端【主体参考】功能可用，API未暴露 |
| **标准分辨率** | ✅ 768x768 | `first_frame_image` 输出标准尺寸 |
| **原图尺寸跟随** | ✅ 支持 | `image` 参数输出跟随原图 |
| **时长选项** | 6s / 10s | 6秒或10秒 |
| **运镜控制** | ✅ 支持 | 15种运镜指令 |

### 2.2 文生视频 (Text-to-Video)

| 能力项 | 支持情况 | 说明 |
|--------|----------|------|
| **纯文本生成** | ✅ 支持 | 仅用prompt生成视频 |
| **运镜控制** | ✅ 支持 | 15种运镜指令 |
| **提示词优化** | ✅ 支持 | 自动优化prompt选项 |

### 2.3 网页端特有功能（API不支持）

| 功能 | 说明 | API支持 |
|------|------|---------|
| **主体参考** | 上传角色图作为参考，不固定首帧 | ❌ 不支持 |
| **角色库** | 保存多个角色供后续使用 | ❌ 不支持 |
| **面部识别** | 自动识别面部特征 | ❌ 不支持 |

### 2.4 角色一致性方案

| 方案 | 效果 | 适用场景 |
|------|------|----------|
| **首尾帧模式** | ⭐⭐⭐⭐⭐ | API可用，最佳一致性 |
| **首帧固定** | ⭐⭐⭐⭐ | API可用，首帧角色固定 |
| **主体参考** | ⭐⭐⭐⭐⭐ | 仅网页端可用，最佳方案 |

## 四、hiyamax使用建议

### 4.1 角色一致性优先场景

| 场景 | 推荐方案 | 工具 |
|------|----------|------|
| **需要API自动化** | 首尾帧模式 | 可灵/海螺API |
| **最佳一致性** | 主体参考功能 | 海螺网页端 |
| **批量生成** | 首帧固定+详细prompt | 可灵/海螺API |
| **人物特写** | LoRA微调 | 可灵1.6 |

### 4.2 参数选择建议

```python
# 方案1: 首尾帧模式（最佳一致性）
{
    "model": "MiniMax-Hailuo-2.3",
    "first_frame_image": "角色图A",
    "last_frame_image": "角色图B",  # 可选
    "prompt": "场景描述",
    "duration": 10
}

# 方案2: 首帧固定
{
    "model": "MiniMax-Hailuo-2.3",
    "first_frame_image": "角色图",
    "prompt": "场景描述 [运镜指令]",
    "duration": 10
}

# 方案3: 文生视频（无参考图）
{
    "model": "MiniMax-Hailuo-2.3",
    "prompt": "详细角色描述 + 场景描述",
    "duration": 10
}
```

## 五、问题与限制

### 5.1 当前限制

1. **海螺API不支持主体参考功能** - 网页端有，API未暴露
2. **可灵API文档较复杂** - 参数多，需要更多测试
3. **角色一致性依赖首帧/首尾帧** - 无法像网页端那样纯参考

### 5.2 待验证问题

- [ ] 可灵是否支持纯参考图模式（不固定首帧）
- [ ] 海螺API是否有未文档化的主体参考参数
- [ ] LoRA微调在API中的可用性
