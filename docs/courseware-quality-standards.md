# 课件单元质量标准 v1.0

> 适用：HiyaMax 中小学数理游戏化课件系统
> 制定：2026-05-17
> 依据：ch10《内能》单元1 样本验证通过

---

## 六条硬性标准

### 1. 交互实验 ≥2 个/单元
- 每个单元必须有至少 2 个可交互的 SVG 动画或动态演示
- 实验必须让学生"看见"物理/数学过程，而非纯文字描述
- 实验后必须跟思考题，引导学生从观察→推理→结论
- 按钮切换型实验优先（不同模式对比观察）

### 2. 例题 ≥3 个/单元，题目可见、答案展开
- `.q`（question）区域：题目完整呈现，**始终可见**
- `.a`（answer）区域：仅放答案、解析、分步，**点击展开**
- 严禁把题目藏在 `.a` 里——学生点之前必须能看到题
- 例题覆盖难度梯度：基础概念 → 情境应用 → 综合/陷阱
- 每个例题必须有 `Step 1/2/3` 分步解析

### 3. 测试 ≥5 题/单元，选项答案匹配
- 概念辨析题：2 题（区分易混淆概念）
- 情境应用题：2 题（生活中的物理/数学现象）
- 陷阱/综合题：1 题（打破直觉、检验深度理解）
- 每题 3-4 个选项，正确答案的 `onclick="checkQuiz(this, true)"` 必须唯一且准确
- 错误选项必须是**常见错误**而非随机干扰
- 严禁出现重复答案（如 A 和 B 选项内容相同）

### 4. 反馈显示正常
- 正确反馈：`✓ 正确！`（不拼接任何选项文字）
- 错误反馈：`✗ 不对，再想想？` + 1.5 秒后重置可重选
- 禁用 `btn.nextElementSibling?.textContent` 等不可靠的 DOM 引用

### 5. 有陷阱题/易错题
- 至少 1 题专门打破学生的常见直觉错误
- 例如："微波炉加热是热辐射吗？"（电磁波≠热辐射）
- 陷阱题后必须有**易错点强调**文字

### 6. 有总结提示
- 单元底部或概念框中必须有**核心区别/核心公式**的强调
- 例如："热传递是能量转移，做功是能量转化"
- 用高对比色（`#ffd166` 黄或 `#06d6a0` 绿）突出

---

## 常见错误清单（禁止项）

| 错误类型 | 示例 | 后果 |
|---|---|---|
| 题目藏在答案区 | `.a` 里放题干 | 学生看不到题 |
| 选项答案重复 | A 和 B 都是 "2.25×10⁴ J" | 学生困惑，无法判断 |
| 反馈引用错误 DOM | `btn.nextElementSibling.textContent` | 显示下一个选项的文字 |
| 纯文字无交互 | 大段概念没有 SVG/动画 | 学生无法"看见"过程 |
| 测试题太少 | 每单元只有 1-2 题 | 无法检验理解深度 |
| 无陷阱题 | 所有题都是直球概念 | 无法暴露理解盲区 |

---

## 验收流程

1. **作者自查**：按六条标准逐条核对
2. **功能测试**：每道测试题都点击一遍（正确/错误选项）
3. **学生视角**：清空缓存，首次访问，确认所有题目可见、交互可用
4. **Scott 抽检**：抽查 20% 单元
