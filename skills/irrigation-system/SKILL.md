### 5.2 数量计算

```
电磁阀数量 = ceil(总喷头用水量 / 水源供水量)
```

**重要规则**：不同种类的喷头/滴灌管必须用不同电磁阀

**计算步骤**：
1. 按喷头类型分组计算流量
2. 每组所需阀数 = ceil(该组流量 / 水源流量)
3. 总阀数 = 各组阀数之和

## 十、给水管道

### 10.1 主管长度

**来源**：用户输入的"花园绿化周长"

```
主管长度 = 花园绿化周长（米）
```

**输入位置**：水源口径下方增加"花园绿化周长"输入框

### 10.2 管道选型规则

| 水源口径 | 电磁阀数量 | 主管规格 | 支管规格 |
|---------|-----------|---------|---------|
| 32mm | - | PPR32管 | PPR25管 |
| 25mm | ≤ 4个 | PPR25管 | PPR25管 |
| 25mm | ≥ 5个 | PPR32管 | PPR25管 |

### 10.3 支管长度计算

### 10.4 管道价格

| 管道 | 材料单价 | 安装单价 | 单价小计 |
|------|---------|---------|---------|
| PPR32管 | 13元/米 | 8.5元/米 | 21.5元/米 |
| PPR25管 | 9元/米 | 8.5元/米 | 17.5元/米 |

### 10.4 支管长度计算

```
支管长度 = Σ(每类喷头数量 × 相应布置间距)
```

**注意**：滴灌管和SuperPRO喷头不计入支管

## 十七、开发规范

### 17.1 输入界面

1. 水源口径选择（25mm/32mm）
2. 支持添加多个绿化区域
3. 每个区域输入：
   - 长度（米）
   - 宽度（米）
   - 植物类型（灌木/草坪/花卉）
   - 位置（边上/中间，宽度>3m时显示）

### 17.2 输出要求

1. 实时预览表格（含材料单价、安装单价、单价小计、合价）
2. Excel导出（标准9列表格格式）
3. 品牌标注完整
4. 汇总行包含8%管理费和9%增值税

### 17.3 计算顺序

1. 喷头/滴灌管选型与数量
2. 滴灌管管件（如有）
3. 千秋架（地埋喷头）
4. 电磁阀（按类型分组计算）
5. 阀门箱
6. 控制器（根据阀数选型）
7. 解码器（如用PROEX-3.0）
8. 雨感器
9. 主管（长边×0.8，减去>10m灌木带）
10. 支管（喷头数×间距）
11. PPR管件（按阀数比例）
12. 控制线（按控制器类型计算长度）
13. 穿线管（=主管长度）
14. 增压泵
15. 土方开挖/回填
16. 汇总（+8% +9%）

## 十八、常见错误规避

| 错误 | 正确做法 |
|------|---------|
| 滴灌管宽度阈值用0.5m | 应该用 **< 1m** |
| 滴灌管安装费按喷头算 | 应该按 **长度×2元/米** |
| 忘记滴灌管管件20% | 必须单独一行 |
| 控制线长度统一计算 | 必须区分PRO-LC和PROEX-3.0 |
| 主管不减去长窄灌木带 | 必须减去 **长度>10米且宽度<2米** 的灌木带和花卉区域 |
| 管道选型只看水源口径 | 25水源+≥5阀时主管用32管 |
