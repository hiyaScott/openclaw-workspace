## 六年级 第一学期

### 第1章 测量的初步
- **1.1 测量的意义**
  - 物理量的概念
  - 测量的必要性
  - 单位制的建立
- **1.2 长度的测量**
  - 长度单位（米、厘米、毫米、微米、纳米）
  - 刻度尺的使用（三看：量程、分度值、零刻度线）
  - 读数方法（估读到分度值下一位）
  - 误差与错误
  - 减小误差的方法（多次测量取平均值、改进测量方法）
- **1.3 体积的测量**
  - 体积单位（立方米、升、毫升）
  - 规则固体体积计算
  - 量筒/量杯的使用（读数时视线与液面最低处平齐）
  - 不规则固体体积测量（排水法）
- **1.4 质量的测量**
  - 质量的概念（物体所含物质的多少）
  - 质量单位（千克、克、吨）
  - 天平的使用（调平、左物右码、砝码夹取）
  - 质量与重量的区别（初中阶段初步区分）
- **1.5 时间的测量**
  - 时间单位（秒、分、时）
  - 秒表的使用

**核心能力**：实验基本操作、有效数字意识
**易错点**：
- 刻度尺读数忘记估读
- 量筒读数视线位置错误
- 天平砝码用手直接接触

### 第2章 声
- **2.1 声波的产生**
  - 声音由物体振动产生
  - 声源的概念
- **2.2 声波的传播**
  - 传播需要介质（固体、液体、气体）
  - 真空不能传声
  - 声速：空气中约340m/s（15°C），固体>液体>气体
  - 回声（回声测距：s = vt/2）
- **2.3 声波的特征**
  - 响度：与振幅有关（单位：分贝dB）
  - 音调：与频率有关（频率单位：赫兹Hz）
  - 音色：与发声体材料和结构有关
  - 人耳听觉范围：20Hz ~ 20000Hz
  - 超声波（>20000Hz）和次声波（<20Hz）
- **2.4 噪声**
  - 噪声的定义
  - 噪声的危害
  - 控制噪声的途径（声源处、传播过程中、人耳处）

**核心能力**：振动-波的思维、实验观察
**易错点**：
- 音调和响度混淆
- 声速在不同介质中的大小关系
- 回声测距忘记除以2

  - 凸透镜的应用：照相机、投影仪、放大镜
  - 人眼与视力矫正（近视、远视）

**核心能力**：光路图绘制、模型抽象
**易错点**：

  - 温度计的原理（液体热胀冷缩）
  - 温度计的使用（玻璃泡不碰底和壁，读数时不取出）
  - 体温计的特殊结构（缩口）
  - 温标：摄氏温度（°C）、热力学温度（K）
- **5.2 热量的传递**

  - 热的不良导体和良导体
- **5.3 比热容**
  - 热量的概念
  - 比热容的定义：c = Q/(m·Δt)
  - 比热容的单位：J/(kg·°C)
  - 水的比热容较大（4.2×10³ J/(kg·°C)）
  - 比热容的应用（海陆风、热水袋）
- **5.4 物态变化**

### 第6章 密度与浮力
- **6.1 密度**
  - 密度的定义：ρ = m/V
  - 密度单位（kg/m³、g/cm³，换算：1g/cm³ = 1000kg/m³）
  - 密度是物质的特性（与质量、体积无关）
  - 密度的测量（固体、液体）
  - 密度的应用（鉴别物质、空心判断）
- **6.2 浮力**
  - 浮力的概念（浸在流体中的物体受到的向上托力）
  - 浮力产生的原因（上下表面压力差）
  - 阿基米德原理：F浮 = ρ液gV排
  - 浮力的测量（称重法：F浮 = G - F拉）
- **6.3 物体的浮沉条件**
  - 比较浮力与重力：F浮 > G 上浮；F浮 = G 悬浮/漂浮；F浮 < G 下沉
  - 比较密度：ρ物 < ρ液 漂浮；ρ物 = ρ液 悬浮；ρ物 > ρ液 下沉
  - 漂浮条件：F浮 = G物，V排 < V物
  - 悬浮条件：F浮 = G物，V排 = V物
- **6.4 浮力的应用**
  - 轮船（空心法增大V排）
  - 潜水艇（改变自身重力）
  - 热气球（改变ρ气）
  - 密度计

**核心能力**：密度计算、浮沉分析
**易错点**：
- 密度与质量/体积成正比的说法（密度是特性，不随m、V变化）
- 漂浮时V排不等于V物
- 阿基米德原理中V排的理解

## 七年级 第二学期

### 第7章 压强
- **7.1 压力与压强**
  - 压力的概念（垂直作用于接触面的力）
  - 压力与重力的区别
  - 压强的定义：p = F/S
  - 压强单位：帕斯卡（Pa）
  - 增大/减小压强的方法
- **7.2 液体的压强**
  - 液体压强的产生
  - 液体压强公式：p = ρgh
  - 液体压强的特点（与深度、密度有关，与容器形状无关）
  - 连通器原理
- **7.3 大气压强**
  - 大气压的存在（马德堡半球实验）
  - 大气压的测量（托里拆利实验）
  - 标准大气压：1atm = 1.01×10⁵ Pa ≈ 760mmHg
  - 大气压与高度的关系（越高气压越低）
  - 沸点与气压的关系
- **7.4 流体压强与流速的关系**
  - 伯努利原理：流速越大，压强越小
  - 飞机升力的产生
  - 火车站安全线

**核心能力**：压强计算、流体分析
**易错点**：
- 压力与重力混淆（只有水平面上自由放置时F=G）
- 液体压强公式中h的理解（深度不是高度）
- 托里拆利实验中管子上提/下压不影响水银柱高度

### 第8章 简单机械
- **8.1 杠杆**
  - 杠杆的五要素（支点、动力、阻力、动力臂、阻力臂）
  - 力臂的画法（支点到力的作用线的垂直距离）
  - 杠杆平衡条件：F₁L₁ = F₂L₂
  - 杠杆的分类（省力杠杆、费力杠杆、等臂杠杆）
- **8.2 滑轮**
  - 定滑轮（不省力，改变力的方向）
  - 动滑轮（省一半力，不改变方向）
  - 滑轮组（F = G/n，n为承担重物的绳子段数）
- **8.3 机械功**
  - 功的定义：W = F·s（力与在力的方向上移动距离的乘积）
  - 功的单位：焦耳（J）
  - 做功的两个必要因素
  - 不做功的三种情况
- **8.4 功率**
  - 功率的定义：P = W/t
  - 功率的物理意义（做功的快慢）
  - 功率单位：瓦特（W）
  - P = F·v 的应用
- **8.5 机械效率**
  - 有用功、额外功、总功
  - 机械效率：η = W有/W总 × 100%
  - 总小于1（η < 100%）
  - 提高机械效率的方法

**核心能力**：杠杆分析、机械效率计算
**易错点**：
- 力臂画错（不是支点到力的作用点的距离）
- 滑轮组中n的判断（数承担动滑轮的绳子段数）
- 机械效率忘记乘100%

### 第10章 简单电路
- **10.1 电路的组成**
  - 电源、用电器、开关、导线
  - 电路图与实物图的对应
  - 通路、断路、短路（电源短路很危险）
- **10.2 串联电路**
  - 串联电路的连接特点
  - 串联电路中电流处处相等：I = I₁ = I₂
  - 串联电路中总电压等于各部分电压之和：U = U₁ + U₂
  - 串联电路中总电阻等于各部分电阻之和：R = R₁ + R₂
- **10.3 并联电路**
  - 并联电路的连接特点
  - 并联电路中总电流等于各支路电流之和：I = I₁ + I₂
  - 并联电路中各支路电压相等：U = U₁ = U₂
  - 并联电路中总电阻的倒数等于各支路电阻倒数之和：1/R = 1/R₁ + 1/R₂
- **10.4 串联与并联电路的应用**
  - 串并联的识别方法
  - 电路设计

**核心能力**：电路分析、串并联规律应用
**易错点**：
- 短路判断错误
- 并联电阻公式求和而不是求倒数和
- 实物图连接时导线要接在接线柱上

## 八年级 第二学期

### 第11章 欧姆定律
- **11.1 电流与电压、电阻的关系**
  - 控制变量法实验
  - 电阻一定时，电流与电压成正比
  - 电压一定时，电流与电阻成反比
- **11.2 欧姆定律**
  - 内容：I = U/R
  - 变形：U = I·R，R = U/I
  - 适用条件：同一段导体、同一时刻
- **11.3 伏安法测电阻**
  - 原理：R = U/I
  - 电路图
  - 滑动变阻器的作用（保护电路、改变电压电流多次测量取平均）
  - 实验步骤与数据处理
- **11.4 串并联电路的电阻关系**
  - 串联：R总 = R₁ + R₂ + ...
  - 并联：1/R总 = 1/R₁ + 1/R₂ + ...
  - n个相同电阻R并联：R总 = R/n
  - 串联分压原理：U₁/U₂ = R₁/R₂
  - 并联分流原理：I₁/I₂ = R₂/R₁
- **11.5 欧姆定律的应用**
  - 电路计算
  - 动态电路分析（滑片移动、开关断开/闭合）

**核心能力**：电路计算、控制变量法
**易错点**：
- R = U/I 用于计算但不是电阻的决定式
- 动态电路分析中电阻变化导致的变化链
- 比例关系搞反（串联分压是正比，并联分流是反比）

---

### 第12章 电功率
- **12.1 电功**
  - 电功的概念（电流做的功）
  - 电功公式：W = U·I·t = P·t = I²·R·t = U²·t/R
  - 电功单位：焦耳（J），常用千瓦时（度）：1度 = 3.6×10⁶ J
  - 电能表（电度表）的读数
- **12.2 电功率**
  - 电功率的概念（电流做功的快慢）
  - 电功率公式：P = U·I = I²·R = U²/R
  - 电功率单位：瓦特（W）
  - 额定功率与实际功率
  - 用电器的铭牌参数
- **12.3 焦耳定律**
  - 电流的热效应
  - 焦耳定律：Q = I²·R·t
  - 纯电阻电路中：Q = W
  - 非纯电阻电路中：Q < W（如电动机）
- **12.4 家庭电路**
  - 家庭电路组成（进户线、电能表、闸刀开关、熔断器、用电器、插座）
  - 火线与零线（电压220V）
  - 开关接火线
  - 金属外壳接地
  - 熔断器/空气开关（电流过大时自动切断：短路或过载）
  - 测电笔的使用
  - 安全用电常识

**核心能力**：电功电功率计算、家庭电路设计
**易错点**：
- 额定功率与实际功率的条件混淆
- 串联电路中P = I²R，并联电路中P = U²/R的灵活选用
- 焦耳定律中Q = I²Rt是最普适的
- 电动机问题中W和Q不相等

  - 法拉第电磁感应定律

  - 感应电流方向（右手定则）
  - 发电机原理（机械能→电能）
  - 交流电与直流电

**核心能力**：电磁关系理解、定则应用
**易错点**：
- 安培定则、左手定则、右手定则混淆
- 电磁感应中"切割"的理解
- 电动机和发电机原理和能量转化混淆

### 第14章 电磁波与通信
- **14.1 电磁波**
  - 电磁波的产生（变化的电流产生电磁波）
  - 电磁波的传播（不需要介质，真空中速度 = 光速 = 3×10⁸ m/s）
  - 电磁波谱（无线电波、微波、红外线、可见光、紫外线、X射线、γ射线）

  - 电视
  - 移动通信

- **14.3 现代通信技术**

**易错点**：

- 波长和频率成反比（c = λf，c一定）

## 九年级 第二学期

### 第15章 原子与原子核
- **15.1 原子**
  - 原子结构（汤姆逊模型→卢瑟福模型）
  - 原子核式结构：原子核（质子+中子）+ 核外电子
  - 质子带正电，电子带负电，中子不带电
  - 原子序数 = 质子数 = 核外电子数
- **15.2 原子核**
  - 放射性现象（α射线、β射线、γ射线）
  - 衰变
  - 核能的利用（裂变、聚变）
  - 核电站原理

**核心能力**：微观世界认知、能源意识
**易错点**：
- α、β、γ射线的穿透力比较（α最弱，γ最强）
- 核能与化学能的区别

### 第16章 能量的转化与守恒
- **16.1 能量的转化**
  - 能量形式的多样性（机械能、内能、电能、光能、化学能等）
  - 能量转化的实例
  - 能量转移与转化的区别
- **16.2 能量守恒定律**
  - 内容：能量既不会凭空产生，也不会凭空消失
  - 转化和转移过程中总量保持不变
  - 永动机不可能制成
- **16.3 能源**
  - 不可再生能源（煤、石油、天然气、核能）
  - 可再生能源（太阳能、风能、水能、生物质能）
  - 能源危机与环境保护

**核心能力**：能量观念、可持续发展意识
**易错点**：
- "能量守恒"不等于"机械能守恒"
- 能量转化有方向性（热力学第二定律，初中阶段初步了解）
