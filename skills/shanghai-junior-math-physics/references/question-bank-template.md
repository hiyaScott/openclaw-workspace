# 出题组卷模板

> 沪教版初中数学物理 · 智能出题系统

---

## 一、出题请求解析

当用户要求出题时，按以下顺序确认参数：

```
科目 → 年级 → 范围（章节/知识点） → 难度分布 → 题型 → 数量 → 用途（练习/测验/考试）
```

**示例对话**：
> 用户："出几道一元二次方程的题"
> 澄清："八年级数学对吧？要涵盖判别式、配方、应用题哪种？基础题还是提高题？"

## 二、难度分级标准

### 数学

| 难度 | 标记 | 特征 | 示例 |
|------|------|------|------|
| 基础 | ⭐ | 直接套公式，一步计算 | 用公式法解 x²-5x+6=0 |
| 提高 | ⭐⭐ | 需变形或两步以上 | 先整理为一般式，再求根；含参数讨论 |
| 拓展 | ⭐⭐⭐ | 综合多个知识点，需构造 | 根的分布与函数图像结合；实际应用建模 |

### 物理

| 难度 | 标记 | 特征 | 示例 |
|------|------|------|------|
| 基础 | ⭐ | 直接套公式，单位统一 | 已知电压电流求电阻 |
| 提高 | ⭐⭐ | 多过程或多公式联立 | 串联分压 + 电功率综合计算 |
| 拓展 | ⭐⭐⭐ | 实验设计或开放分析 | 设计电路测未知电阻；故障排查 |

## 五、题目生成策略

### 变式题生成法
拿到一道母题，按以下维度变式：

1. **改数字**：系数、常数变化
2. **改条件**：去掉一个条件，或增加限制
3. **改问法**：正向→逆向；求值→判断存在性
4. **改情境**：纯数学 → 生活实际 → 跨学科
5. **改方法**：公式法 → 因式分解法 → 配方法

**示例**：
母题：解 x² - 5x + 6 = 0
- 变式1：解 x² - 5x - 6 = 0（改常数，训练符号）
- 变式2：若 x² - 5x + k = 0 有两个不等实根，求 k 范围（改问法）
- 变式3：矩形长比宽多5，面积6，求长和宽（改情境）
- 变式4：用配方法解（改方法）

### 常见错误选项设计
选择题的干扰项要"有理有据"：
- 运算错误：-b 当 b 为负时算错
- 概念错误：判别式 Δ=0 时说"一个根"
- 漏解：开方只取正
- 符号错误：不等式乘负忘变号

## 六、自动组卷算法（参考）

```
输入：
  - 科目（math/physics）
  - 年级（6/7/8/9）
  - 章节列表
  - 难度比例（基础:提高:拓展 = 6:3:1）
  - 总分（默认100）
  - 时间（默认60分钟）

处理：
  1. 根据章节从题库筛选候选题
  2. 按难度比例随机抽题
  3. 确保知识点覆盖度 ≥ 80%
  4. 检查总分是否匹配
  5. 生成试卷 + 答案 + 评分标准

输出：
  - 试卷（Markdown/HTML）
  - 答案与解析
  - 双向细目表（知识点×题型×难度 矩阵）
```
