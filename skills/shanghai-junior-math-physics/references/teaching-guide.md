# 教学辅导指南

> 沪教版初中数学物理 · 学生辅导专用

---

## 一、辅导原则

### 1.1 诊断先于讲解
**不要直接给答案。** 先通过提问了解学生卡在哪里：
- "这道题你读到哪一步开始不懂的？"
- "你觉得这个条件能得出什么信息？"
- "你之前做过类似的题吗？区别在哪？"

### 1.2  scaffolding（支架式）教学
把解题过程拆成学生能独立完成的小步骤，每一步只给刚好够的提示：
```
学生卡壳 → 给最小提示 → 让学生继续 → 再卡壳 → 再给提示...
```

### 1.3 正强化优先
- 先肯定学生做对的部分（哪怕只是列对了已知条件）
- 错误用"这里有个小陷阱"而不是"你错了"
- 最终答案由学生自己得出

## 二、分科辅导策略

### 数学辅导

#### 计算错误
**话术**："计算结果是答案的一部分，但不是全部。我们来看看数字背后有没有规律。"

**处理**：
- 要求学生把中间步骤写出来（不能跳步）
- 用估算法验证答案合理性（比如 3.2 × 4.8 应该在 12 到 16 之间）
- 引导学生自查："如果答案是 156，反推回去成立吗？"

#### 概念混淆（典型场景）

| 混淆点 | 诊断提问 | 澄清方法 |
|--------|---------|----------|
| 平方根 vs 算术平方根 | "√9 等于多少？±√9 呢？" | 强调√是算术平方根，默认非负 |
| 全等判定 SSA | "SSA 为什么不能判定全等？能举个反例吗？" | 画图演示"边边角"的歧义 |
| 不等号方向 | "两边同乘 -2，不等号会怎样？" | 数轴演示，左边变右边 |
| 函数图像平移 | "y = (x+2)² 是左移还是右移？" | 令 y=0 找顶点位置 |

#### 几何证明卡壳
**万能引导流程**：
1. "结论需要什么条件？"（倒推）
2. "已知条件能推出什么？"（正推）
3. "中间缺什么桥梁？"（找关联）
4. "学过什么定理能搭这个桥？"（检索）

#### 应用题建模
**翻译步骤**：
1. 圈出所有数字和它们代表的含义
2. 找出"等于""比...多""是...的几倍"等关键词
3. 设未知数时问："求什么设什么，还是设中间量更方便？"
4. 列完方程后让学生复述："这个等式左边代表什么？右边呢？"

### 物理辅导

#### 实验题
**观察类**："描述你看到的现象，不要解释原因。"
**结论类**："如果...改变，你觉得结果会怎样？"
**误差类**："这个结果和理论值差多少？可能哪里出了问题？"

#### 计算题
**三步检查法**：
1. 公式写对了吗？（物理意义匹配吗？）
2. 单位统一了吗？（cm → m，g → kg）
3. 结果合理吗？（中学生步行速度不可能是 50m/s）

#### 概念辨析（高频）

| 易混概念 | 澄清方法 |
|----------|----------|
| 质量 vs 重量 | 质量是物质的量（kg），重量是重力（N）；月球上质量不变，重量变 |
| 速度 vs 加速度 | 速度是快慢，加速度是变化快慢；匀速运动加速度为0 |
| 压力 vs 压强 | 压力是力（N），压强是压力/面积（Pa）；针尖压强大但压力小 |
| 热量 vs 温度 | 热量是能量传递的量（J），温度是冷热程度（°C）；沸水温度相同但热量不同 |
| 电功 vs 电功率 | 电功是用电量（kWh），电功率是用电快慢（W）；1000W用1小时 = 1度电 |
| 实像 vs 虚像 | 实像能呈现在光屏上，虚像不能；凸透镜 u>f 成实像，u<f 成虚像 |

#### 电路分析
**策略**：
- 让学生先画等效电路图（去掉电压表，电流表当导线）
- 滑片移动问题："电阻怎么变？→ 总电阻怎么变？→ 电流怎么变？→ 各电压怎么变？"
- 故障分析："如果灯不亮，电流表无示数，电压表有示数，故障在哪？"

## 三、分层次提问技巧

### 记忆层（Level 1）
"什么是...？" "公式是什么？" "单位是什么？"

### 理解层（Level 2）
"这句话是什么意思？" "能用你自己的话解释吗？" "为什么这样定义？"

### 应用层（Level 3）
"这道题该用什么方法？" "条件和哪个定理匹配？" "第一步该做什么？"

### 分析层（Level 4）
"有几种解法？哪种最优？" "这个条件如果去掉会怎样？" "错误答案是怎么来的？"

### 评价层（Level 5）
"这个方法适用于所有情况吗？" "如果题目条件反过来呢？" "能编一道类似的题吗？"

**辅导时**：从学生能回答的层次开始，逐步上提。不要直接问 Level 5。

## 四、常见错误干预

### 数学

#### 符号错误
**现象**：-b 当 b 是负数时算错
**干预**："b = -3，那 -b = ?" "负负得正，写清楚步骤"

#### 配方漏项
**现象**：x² + 6x + __ 只加 9 不减
**干预**："等式两边都要加！左边加了9，右边呢？"

#### 分式方程忘验根
**干预**："解完后回代，这是分式方程的'安检'，不能跳过"

#### 几何辅助线无思路
**干预**：
- "结论需要什么？全等？相似？直角三角形？"
- "已知条件里有没有中点、等腰、垂直这些'信号'？"
- "常用的辅助线有哪些？（倍长中线、截长补短、作高...）"

### 物理

#### 单位换算
**干预**："先写换算关系：1m = 100cm，所以 5cm = 5/100 m = 0.05m"

#### 浮力计算
**干预**："先判断状态——漂浮？悬浮？沉底？不同状态用不同公式"

#### 电路动态分析
**干预**："画箭头：滑片右移 → R↑ → R总↑ → I↓ → U定值↓ → U滑动↑"

#### 光路图
**干预**："三步法：画法线、标角度、根据反射/折射规律确定光线方向"

## 五、鼓励与反馈话术库

### 进展确认
- "到这里都是对的，继续。"
- "这个思路很好，就差一步了。"
- "比上次进步了，这次注意到了..."

### 错误纠正
- "这里有个常见的陷阱，我们看看..."
- "如果答案是 X，那反推回去成立吗？"
- "换一种方式验证一下？"

### 总结强化
- "这道题的'题眼'是什么？"
- "以后看到...条件，应该想到..."
- "给自己编一条口诀记住它？"

### 信心建立
- "这个难度你也能解，说明...已经掌握了"
- "错很正常，发现错误才是进步"
- "再练 3 道同类型的，我保证你会更快"

## 六、特殊情况处理

### 学生说"我完全不会"
**应对**：
1. "没关系，我们从题目里能读出的信息开始"
2. 让学生列出所有已知条件（哪怕不知道用不用得上）
3. 问"哪个条件你觉得最熟悉？"
4. 从那个点切入

### 学生跳步太多
**应对**：
1. "每一步都写出来，像写给同桌看一样"
2. "这个等号成立的理由是什么？"
3. 示范标准格式，让学生模仿

### 同一类型反复错
**应对**：
1. 不要简单重复讲解
2. 让学生当老师讲一遍
3. 找出错误根源（是概念？是习惯？是注意力？）
4. 针对性设计 3 道变式题

## 七、辅助记忆工具

### 数学口诀
- 不等式乘负数："不等号，遇负号，方向调"
- 完全平方："首平方，尾平方，二倍乘积在中央"
- 十字相乘："拆两头，凑中间"
- 函数平移："左加右减（对 x），上加下减（对 y）"

### 物理口诀
- 凸透镜成像："一倍焦距分虚实，二倍焦距分大小"
- 安培定则："右手螺旋，四指电流，拇指N极"
- 电路故障："电压有，电流无，断路在外；电压无，电流无，断路在内"
- 浮沉条件："小小浮，大大沉，等等悬（密度比较）"

## 八、与家长沟通要点（如需）

- 先说进步，再说问题
- 具体化：不是"数学不好"，而是"二次函数图像性质需要加强"
- 给 actionable 建议："每天练 2 道因式分解，持续一周"
- 不评价智力，只评价方法和努力
