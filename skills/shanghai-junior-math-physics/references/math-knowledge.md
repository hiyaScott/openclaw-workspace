## 六年级 第一学期

### 第1章 数的整除
- **1.1 整数与整除**
  - 整数的概念与分类（正整数、零、负整数）
  - 整除的定义：a ÷ b = c 且余数为0
  - 整除的判定方法
- **1.2 能被2、5整除的数**
  - 偶数与奇数的定义
  - 末位判定法（2看末位，5看末位0或5）
  - 能被10整除的数
- **1.3 能被3、9整除的数**
  - 数字和判定法
  - 弃九法原理
- **1.4 素数、合数与分解素因数**
  - 素数与合数的定义
  - 100以内素数表
  - 短除法分解素因数
  - 素因数的唯一分解定理
- **1.5 公因数与最大公因数**
  - 公因数、最大公因数（GCD）
  - 互素的概念
  - 辗转相除法（欧几里得算法）
  - 分解素因数法求GCD
- **1.6 公倍数与最小公倍数**
  - 公倍数、最小公倍数（LCM）
  - 分解素因数法求LCM
  - GCD与LCM的关系：GCD(a,b) × LCM(a,b) = a × b

**核心能力**：数的性质分析、算法思维（辗转相除）
**易错点**：
- 1不是素数也不是合数
- 混淆"能被...整除"和"是...的倍数"
- 辗转相除时顺序搞反

### 第2章 分数
- **2.1 分数与除法**
  - 分数的意义（把单位"1"平均分成若干份）
  - 分数与除法的关系：a÷b = a/b
  - 真分数、假分数、带分数
- **2.2 分数的基本性质**
  - 分子分母同乘/同除相同数（非零），分数值不变
  - 约分与通分
  - 最简分数
- **2.3 分数的大小比较**
  - 同分母比较
  - 同分子比较
  - 通分后比较
  - 与1/2、1等基准数比较
- **2.4 分数的加减法**
  - 同分母加减
  - 异分母加减（先通分）
  - 带分数的加减
- **2.5 分数的乘除法**
  - 分数乘法：分子乘分子，分母乘分母
  - 分数除法：乘以倒数
  - 带分数的乘除（先化假分数）
  - 分数运算的应用题

**核心能力**：分数运算的熟练度、约分技巧
**易错点**：
- 带分数加减时直接加减整数和分数部分
- 除法变乘法时忘记取倒数
- 约分不彻底

### 第3章 比和比例
- **3.1 比的意义**
  - 比的概念（a:b 或 a/b）
  - 比与除法、分数的关系
  - 比的各部分名称（前项、后项、比值）
- **3.2 比的基本性质**
  - 比的前项和后项同乘/同除相同数（非零），比值不变
  - 最简整数比
  - 连比的化简
- **3.3 比例**
  - 比例的定义：a:b = c:d
  - 比例的基本性质：外项积 = 内项积
  - 解比例方程
- **3.4 百分比的意义**
  - 百分比的定义
  - 百分数与小数、分数的互化
  - 百分比的应用（增长率、折扣、利率）
- **3.5 百分比的应用**
  - 求一个数的百分之几
  - 已知一个数的百分之几是多少，求这个数
  - 增加/减少百分之几
  - 利息计算

**核心能力**：比例思维、百分比应用
**易错点**：
- 百分比增减的基数搞错
- "增加到" vs "增加了" 区分不清

  - 周长公式：C = πd = 2πr

  - 面积公式：S = πr²
  - 圆环面积
- **4.3 扇形**
  - 扇形的定义
  - 扇形面积公式：S = (n/360) × πr²

  - 法则法（正数>0>负数；两个负数，绝对值大的反而小）

  - 同号相加、异号相加

  - 加减混合运算
- **5.6 有理数的乘法**
  - 乘法法则（同号得正，异号得负）
  - 乘法的交换律、结合律、分配律
  - 多个有理数相乘的符号法则
- **5.7 有理数的除法**
  - 除法法则：a ÷ b = a × (1/b)

### 第17章 一元二次方程
- **17.1 一元二次方程的概念**
  - 定义：ax² + bx + c = 0（a≠0）
  - 一般式、各项名称
  - 方程的根
- **17.2 一元二次方程的解法**
  - **直接开平方法**（x² = a 型）
  - **因式分解法**（十字相乘法、提取公因式）
  - **配方法**
    - 步骤：移项 → 二次项系数化为1 → 配方（加一次项系数一半的平方）→ 开方
    - 配方法的原理（完全平方公式）
  - **公式法（求根公式）**
    - 求根公式：x = [-b ± √(b²-4ac)] / 2a
    - 判别式：Δ = b² - 4ac
    - Δ > 0：两个不等实根
    - Δ = 0：两个相等实根
    - Δ < 0：无实根
- **17.3 一元二次方程的根与系数关系（韦达定理）**
  - x₁ + x₂ = -b/a
  - x₁ × x₂ = c/a
  - 应用：已知根求系数、构造方程
- **17.4 一元二次方程的应用**
  - 增长率/降低率问题
  - 利润问题
  - 几何图形面积问题
  - 动点问题

**核心能力**：配方思想、判别式分析、建模能力
**易错点**：
- 配方时只加不减（等式两边都要加）
- 判别式中忘记a≠0的前提
