# CapabilityEvolver - 能力进化器

## 核心定位

CapabilityEvolver 是 ClawHub 下载量第一的插件（35,000+），它是一个**元技能（Meta-Skill）**——不是添加特定能力，而是让 AI 通过使用过程**自我进化**。

> "装了不会立刻有变化，但用一两周后，它越来越懂你"

## 工作原理

### GEP 基因进化协议

```
┌─────────────────────────────────────────────────────────────┐
│  1. 观察 (Observe)                                          │
│     ↓ 扫描会话历史 (~/.openclaw/agents/*.jsonl)            │
│  2. 分析 (Analyze)                                          │
│     ↓ 识别高频任务、重复错误、低效模式                      │
│  3. 生成 (Generate)                                         │
│     ↓ 自动创建新的 Skill 或优化现有流程                     │
│  4. 沉淀 (Preserve)                                         │
│     ↓ 将优化固化为可复用的"基因资产"                        │
│  5. 应用 (Apply)                                            │
│     ↓ 动态注入到后续会话中                                  │
└─────────────────────────────────────────────────────────────┘
```

### 进化触发条件

| 触发方式 | 说明 |
|----------|------|
| 手动触发 | 输入 `/evolve` 命令 |
| 定时触发 | 每周自动分析一次 |
| 事件触发 | 连续3次同类错误后自动分析 |

## 核心能力

### 1. 任务模式识别
- 识别你每天重复做的任务
- 发现你的工作习惯和偏好
- 分析你的沟通风格

**示例**: 
- 发现你每天早上9点检查邮件 → 自动生成"晨间邮件简报"skill
- 发现你经常把网页内容转成Markdown → 自动生成"网页转笔记"skill

### 2. 错误自动修复
- 记录你纠正 AI 的方式
- 分析错误根本原因
- 生成补丁防止再次犯错

**示例**:
- 你多次纠正"用中文回复"→ 自动记住偏好
- 你发现 AI 经常误解某个术语 → 自动生成术语表

### 3. 个性化优化
- 调整回复长度和风格
- 优化工具调用顺序
- 学习你的行业术语

**实际案例**:
> 某用户两周内，CapabilityEvolver 自动生成了 7 个新 Skill：
> - 行业简报自动整理
> - 客户沟通记录归档
> - 代码审查清单生成
> - 会议纪要格式化
> - 待办事项优先级排序
> - 文档版本对比
> - 周报自动生成

## 使用方法

### 基础使用
```
/evolve          # 手动触发进化分析
/evolve --force  # 强制重新分析全部历史
/evolve --dry    # 预览将要生成的变更
```

### 配置进化方向
```
设置进化模式为保守: 只修复明显错误
设置进化模式为平衡: 修复错误 + 小幅优化
设置进化模式为激进: 主动尝试新能力
```

## 资产沉淀

所有进化成果存储在:
```
~/.openclaw/evolver/
├── assets/              # 基因资产
│   ├── patterns/        # 识别的模式
│   ├── patches/         # 自动修复补丁
│   └── skills/          # 生成的新技能
├── logs/                # 进化历史
└── config.yaml          # 进化配置
```

## 最佳实践

1. **给足观察时间** - 至少使用1-2周再评估效果
2. **主动纠正错误** - 你纠正得越多，AI学得越快
3. **定期回顾生成物** - 检查自动生成的 skill 是否符合预期
4. **备份重要资产** - 定期备份 `~/.openclaw/evolver/assets/`

## 注意事项

- **隐私**: 分析仅在本地进行，数据不会上传
- **控制**: 所有生成物需经你确认才会生效
- **回滚**: 支持回退到之前的进化版本
