# AI短片Pipeline Skill

## 核心工作流（5步法）

```
Step 1: 创意概念 → Step 2: 角色设计 → Step 3: 场景设计 → Step 4: 分镜首帧 → Step 5: 视频生成 → Step 6: 后期剪辑 → 发布
```

### Step 1: 创意概念

**目标**：确定故事核心和视觉风格

**执行流程**：
1. 深度访谈——追问核心元素、情感基调、目标时长
2. 输出3-5个剧本方向供选择
3. 四幕结构设计（开场/催化剂/中点/结局）
4. 创建Pipeline数据文件和项目页面

**产出物**：
- 概念文档（钩子、主题、角色、世界观）
- 四幕结构剧本
- 视觉风格参考
- Pipeline项目初始化

---

### Step 2: 角色设计

**目标**：创建可复用的角色资产

**执行流程**：
1. 生成3-5个角色方案
2. 用户评审反馈
3. 迭代优化直到确认
4. **自动执行**：生成三视图（正视图/侧视图/背视图）
5. **自动执行**：归档旧版本，标记当前版本

**产出物**：
- 角色设计图
- 三视图（front/side/back）
- 角色一致性规范

**数据规范**：
```json
{
  "threeViews": {
    "front": {"image": "xxx_front.png", "thumbnail": "xxx_front_thumb.jpg", "desc": "..."},
    "side": {"image": "xxx_side.png", "thumbnail": "xxx_side_thumb.jpg", "desc": "..."},
    "back": {"image": "xxx_back.png", "thumbnail": "xxx_back_thumb.jpg", "desc": "..."}
  }
}
```

---

### Step 3: 场景设计

**目标**：建立完整的场景资产库

**执行流程**：
1. 按镜头需求列出场景清单
2. 定义每个场景的光线、色彩、情绪
3. 批量生成场景图
4. 用户筛选（可用/需重绘）
5. 重绘+归档，版本迭代

**性能优化**：
- 缩略图标准：400x250px, JPEG 85%, ~15KB
- 压缩比：原图4MB → 缩略图15KB（266倍压缩）

---

### Step 4: 分镜首帧

**目标**：可视化每个镜头的关键画面

**执行流程**：
1. 按16个镜头拆分剧本
2. 设计每个镜头的首帧画面
3. 生成首帧/尾帧静态图
4. 用户确认分镜

**产出物**：
- 分镜表（镜头号、时间、景别、动作）
- 首帧/尾帧图（带缩略图）

---

### Step 5: 视频生成【高风险环节】

**⚠️ 严格控制规则**：
1. **必须获得用户明确授权**："可以开始生成"
2. **控制API调用频率**：每次调用间隔≥30秒
3. **设置预算上限**：超出必须停止并请示
4. **记录所有调用**：便于审计和复盘

**执行流程**：
1. 编写详细的运动描述提示词
2. 使用AI视频工具（可灵/海螺/Runway）
3. 批量生成（控制频率！）
4. 初步筛选结果
5. 用户最终选择

**产出物**：
- MP4视频片段
- 生成参数记录

---

### Step 6: 后期剪辑

**目标**：输出完整成片

**执行流程**：
1. 按分镜顺序粗剪
2. FFmpeg添加硬字幕（注意中文字体支持）
3. 添加BGM和音效
4. 调色统一
5. 用户审核-调整循环
6. 输出1080p成片

## 人机协作规范

### 角色分工

| 角色 | 职责 | 决策权 |
|------|------|--------|
| **用户（导演）** | 创意方向、关键决策、质量审核 | 创意决策、版本锁定、资金授权 |
| **AI（助手）** | 技术实现、资产管理、版本控制、流程记录 | 技术选型建议、自主QA |

### 协作原则

1. **决策前置**
   - AI不提供"唯一答案"，提供"选择空间"
   - 关键决策必须获得用户确认

2. **实时同步**
   - Pipeline页面即进度看板
   - 每完成一个资产立即更新
   - 重要决策当天记录到memory

3. **质量门禁**
   - **高风险操作**（API调用/资金支出）：必须明确授权
   - **用户验收前**：AI必须完成自检（QA脚本）
   - **预算控制**：设置上限，超额停止

4. **责任边界**
   - 用户：提供清晰需求、及时反馈、关键决策
   - AI：技术实现、资产管理、自主QA、流程记录

### 禁止行为（红线）

- ❌ 未经用户确认擅自批量提交API调用
- ❌ 用户说"停"后不立即停止
- ❌ 遇到困难不请示，自己乱试
- ❌ 把"做完"放在"做对"前面

## Pipeline数据规范

### 项目结构

```
project/
├── pipeline.html              # 展示页面
├── pipeline/data/
│   └── project_name.json      # 项目数据
└── assets/
    └── project_name/
        ├── thumbnails/        # 缩略图（72个文件）
        ├── scenes/            # 场景原图
        ├── shots/             # 首帧原图
        └── videos/            # MP4片段
```

## 检查清单

### 发布前QA检查

- [ ] 所有图片都有缩略图
- [ ] 缩略图路径包含 `thumbnails/` 子目录
- [ ] JSON中所有thumbnail字段不为空或"N/A"
- [ ] 所有文件已推送到GitHub
- [ ] Pipeline页面可正常访问
- [ ] 移动端显示正常

### API调用前检查

- [ ] 已获得用户明确授权
- [ ] 账户余额充足
- [ ] 设置了调用间隔限制（≥30秒）
- [ ] 设置了最大重试次数（≤5次）
- [ ] 区分了"提交"和"查询"API端点
