## 一、工具概览与选择指南

### 工具对比矩阵

### 选择决策树

```
需要生成视频？
├── 是 → 需要人物/角色？
```

## 二、可灵 (Kling) 图生视频

### 2.1 核心参数

| 参数 | 选项 | 建议 |
|------|------|------|
| **模式** | 标准/专业 | 专业模式质量更好 |
| **时长** | 5秒/10秒 | 先用5秒测试，确认后再生成10秒 |
| **比例** | 16:9 / 9:16 / 1:1 | 根据平台选择（B站16:9，抖音9:16）|
| **运动幅度** | 低/中/高 | 人物用"中"，风景用"高" |

### 2.2 提示词公式

```
[镜头运动] + [主体动作] + [环境互动] + [氛围/光线变化]
```

**示例**：
```
慢推镜头，机器人缓缓转头看向花朵，夕阳余晖洒在金属表面，
警示灯微弱闪烁，背景废墟渐变暗
```

### 2.3 最佳实践

1. **首帧质量决定视频质量**
   - 确保首帧清晰、构图完整
   - 人物面部要清晰（特别是眼睛）

2. **运动描述要具体**
   - ❌ "机器人移动"（太模糊）
   - ✅ "机器人履带缓慢前进，机械臂轻轻抬起"（具体动作）

3. **控制运动幅度**
   - 人物视频用"中"幅度（避免变形）
   - 风景/场景用"高"幅度（增加动感）

4. **API调用注意事项**
   - 每次调用间隔 ≥ 30秒
   - 批量生成前先测试1个
   - 设置最大重试次数（≤5次）

### 2.4 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 人物变形 | 运动幅度过大 | 降低幅度，分段生成 |
| 画面闪烁 | 首帧光影对比强烈 | 调整首帧光线，使其柔和 |
| 背景扭曲 | 运动描述不清晰 | 补充环境描述 |
| 生成失败 | 队列繁忙 | 等待几分钟后重试 |

## 三、海螺 (Hailuo) 视频生成

### 3.1 核心参数

| 参数 | 选项 | 建议 |
|------|------|------|
| **分辨率** | 720P/1080P | 1080P质量更好 |
| **时长** | 6秒 | 固定6秒 |

### 3.2 提示词公式

```
[镜头类型] + [主体] + [动作] + [环境] + [氛围词]
```

**示例**：
```
特写镜头，生锈的机器人捧着白色小花，机械手指微微颤动，
暴雨中，雨水顺着金属表面流下，暖色调逆光，电影感，4K画质
```

### 3.3 最佳实践

1. **氛围感是强项**
   - 海螺擅长营造情绪氛围
   - 多使用氛围词（"电影感"、"梦幻"、"赛博朋克"）

2. **光线描述要详细**
   - 明确光源方向和强度
   - "金色逆光"比"阳光"效果更好

3. **避免复杂动作**
   - 人物转头、抬手等简单动作效果好
   - 复杂动作（奔跑、打斗）容易崩

### 3.4 API调用（DMXAPI）

⚠️ **高风险操作，必须严格控制**

```python
# 错误示例：会导致资金浪费！
while not completed:
    response = requests.post(API_URL, ...)  # 每次都在创建新任务！
    time.sleep(10)
```

**正确做法**：
```python
# 1. 先提交任务
response = requests.post(API_URL, json={"prompt": ..., "image": ...})
task_id = response.json()["task_id"]

# 2. 使用task_id查询（不是重新提交！）
for i in range(max_retries):
    result = requests.post(API_URL, json={"task_id": task_id})
    if result.json()["status"] == "completed":
        break
    time.sleep(30)  # 至少30秒间隔
```

## 四、豆包 图生图

### 4.1 最佳使用场景

- **角色设计**：中文描述，理解准确
- **首帧生成**：与提示词匹配度高
- **批量生成**：快速出图，筛选效率高

### 4.2 提示词公式

```
[风格] + [主体] + [细节特征] + [光线] + [氛围] + [质量词]
```

**示例**：
```
皮克斯风格，可爱的机器人，生锈的金属质感，圆形复古眼睛，
双手捧着白色小花，夕阳逆光，暖色调，高清，8K
```

### 4.3 角色一致性技巧

1. **固定关键描述词**
   - 每次保留相同的风格词和特征词
   - 只改变姿势/角度描述

2. **使用种子值**
   - 记录满意的图片种子
   - 后续生成使用相同种子

3. **三视图生成**
   - 先生成正视图
   - 用正视图作为参考图生成侧视图
   - 保持描述词95%相同

## 五、即梦 图生图

### 5.1 最佳使用场景

- **写实场景**：照片级真实感
- **三视图**：细节清晰，结构准确
- **氛围场景**：光影效果出色

### 5.2 提示词特点

即梦对**光线**和**材质**的描述响应很好：

```
写实风格，末世废墟中的机器人，生锈金属表面，
夕阳金色逆光，体积光，暖色调，景深效果，8K超清
```

### 5.3 即梦v2.0模型

- 效果更好但消耗积分更多
- 重要场景使用v2.0
- 预览/测试用v1.0

## 六、工具组合工作流

### 推荐组合

**写实短片**（如"第147天"）：
1. **角色**：豆包生成 → 即梦v2.0细化 → 豆包三视图
2. **场景**：即梦v2.0
3. **首帧**：豆包（与角色一致性好）
4. **视频**：可灵（人物）+ 海螺（场景）

**卡通/风格化短片**：
1. **所有素材**：豆包统一生成
2. **视频**：可灵（保持一致性）

## 七、成本控制策略

### 7.1 分阶段投入

| 阶段 | 投入比例 | 说明 |
|------|----------|------|
| 概念验证 | 10% | 快速出图，确定方向 |
| 资产生产 | 50% | 高质量生成 |
| 视频生成 | 30% | 先用5秒测试，确认后生成10秒 |
| 后期调整 | 10% | 修复和优化 |

### 7.2 降本技巧

1. **先用免费工具验证**
   - 豆包免费额度做概念设计
   - 确认方向后再用付费工具

2. **缩略图预览法**
   - 先用小尺寸/低质量预览
   - 确认后再生成高清版

3. **批量生成控制**
   - 每次批量≤5个
   - 确认效果后再继续

4. **复用已有素材**
   - 同项目内复用角色设计
   - 跨项目复用通用场景

## 八、故障排查速查表

| 现象 | 可能原因 | 解决方案 |
|------|----------|----------|
| 生成结果与描述不符 | 提示词模糊 | 增加细节描述，使用具体词汇 |
| 人物面部崩坏 | 首帧质量问题 | 重新生成首帧，确保面部清晰 |
| 视频闪烁/抖动 | 运动幅度过大 | 降低幅度，分段描述动作 |
| 生成队列长时间等待 | 高峰期 | 避开晚上8-11点高峰 |
| API返回错误 | 额度不足/参数错误 | 检查账户余额，验证参数格式 |
| 下载失败 | CDN问题 | 等待几分钟后重试，或更换网络 |
