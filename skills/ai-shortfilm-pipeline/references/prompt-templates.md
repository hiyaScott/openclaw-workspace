# 提示词模板库

> AI短片制作各环节的提示词模板，提高一致性和效率

---

## 一、即梦AI图生图最佳实践

### 1.1 提示词公式（经搜索验证）

```
[主体] + [细节描述] + [场景环境] + [艺术风格] + [光线/氛围] + [质量词]
```

**中文提示词效果更优**，即梦对中文理解更好。

### 1.2 关键参数设置

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| **参考强度** | 60-90% | 控制创意空间，越高越接近参考图 |
| **风格强度** | 50%（默认）<br>70-80%（强化风格） | 要强化特定风格特征时调高 |
| **精细度** | 风景图: 8-10级<br>卡通插画: 5-7级 | 精细度越高生成越慢，质量越好 |
| **比例** | 9:16（短视频）<br>16:9（横版海报）<br>1:1（社交配图） | 根据最终用途选择 |

### 1.3 提示词优化原则

**❌ 避免模糊形容词**：
- "好看的背景" → ❌
- "精致的细节" → ❌
- "美丽的光线" → ❌

**✅ 用具体描述**：
- "淡蓝色渐变背景，从左到右由深变浅" → ✅
- "金属表面有细密的划痕和氧化斑点" → ✅
- "侧光从画面左上方45度角照射，形成明暗对比" → ✅

**✅ 长度控制**：
- 最佳长度：**50-150字**
- 太短 → 细节不足，AI自由发挥过多
- 太长 → 重点被稀释，反而效果差

**✅ 核心信息前置**：
- 最重要的描述放在前面
- 即梦会优先处理前50个token

### 1.4 即梦图生图完整示例

      履带式底座，机械关节有工业铆钉细节，双手捧着一朵白色小花

## 二、海螺AI视频生成最佳实践

### 2.1 提示词公式

```
[镜头运动] + [主体动作] + [环境互动] + [光线/氛围变化] + [速度/节奏]
```

### 2.2 15种运镜指令（海螺支持）

| 中文指令 | 英文术语 | 效果描述 |
|----------|----------|----------|
| 推近 | Push in / Dolly in | 镜头向前推进，强调主体 |
| 拉远 | Pull back / Dolly out | 镜头向后拉远，展示环境 |
| 左摇 | Pan left | 镜头水平向左移动 |
| 右摇 | Pan right | 镜头水平向右移动 |
| 上升 | Crane up / Rise | 镜头向上移动，营造宏大感 |
| 下降 | Crane down / Fall | 镜头向下移动，聚焦细节 |
| 环绕 | Orbit / Circle around | 镜头围绕主体360度旋转 |
| 跟随 | Follow / Track | 镜头跟随移动的主体 |
| 固定 | Static / Locked off | 镜头静止不动 |
| 手持晃动 | Handheld | 模拟手持摄影的轻微晃动 |
| 低角度 | Low angle | 从下往上拍摄，增强主体气势 |
| 高角度 | High angle | 从上往下拍摄，营造渺小感 |
| 主观视角 | POV / First-person | 模拟角色眼睛视角 |
| 过肩 | Over-the-shoulder | 从角色肩膀后方拍摄 |
| 特写推进 | Push in to close-up | 从远景推进到特写 |

### 2.3 进阶技巧

**组合运镜限制**：
- ❌ 不超过3个运镜组合
- ✅ 推荐1-2个简单运镜
- 示例：`镜头缓慢推近，同时微微上升`

**时长控制**：
- 单镜头时长：**3-5秒最佳**
- 太长 → 动作不自然，AI难以维持一致性
- 剪辑时多个短镜头组合效果更好

**术语选择**：
- 海螺同时支持中英文术语
- 英文术语识别度更高：`High angle`, `Low angle`, `POV`, `Dolly in`
- 复杂描述用中文更精准

### 2.4 动作描述最佳实践

**具体优于抽象**：
- ❌ "踱步" → 太模糊
- ✅ "走到画面右侧" → 具体可执行

**分步描述复杂动作**：
```
第一步：机器人头部缓缓转向左侧
第二步：机械臂抬起，手指轻轻触碰花朵
第三步：身体微微前倾，保持守护姿态
```

**速度控制词**：
- 极慢：extremely slow, glacial
- 缓慢：slow, gentle, gradual
- 正常：normal speed
- 快速：fast, quick, rapid

### 2.5 海螺视频生成完整示例

**示例1：机器人守护镜头**
```
镜头缓慢推近（Slow push in），
机器人头部缓缓转向花朵，机械手指微微收紧护住花瓣，
夕阳余晖在生锈的金属表面缓慢移动形成光影变化，
背景废墟逐渐变暗，从暖色调转为冷蓝色调，
电影感慢节奏，4秒时长
```

**示例2：暴雨保护镜头**
```
特写镜头（Close-up），手持晃动效果（Handheld），
机器人用机械臂和身体护住花朵，雨水顺着金属表面流下，
闪电每3秒照亮场景一次，机器人在风雨中轻微晃动但保持稳定，
冷色调主导（蓝灰），暖色警示灯以2秒间隔闪烁，
紧张但坚定的氛围，3秒时长
```

**示例3：POV主观镜头**
```
POV视角（First-person view），
从机器人眼睛高度看向手中的花朵，
镜头轻微呼吸感晃动，
焦点在花朵上，背景废墟虚化，
夕阳在镜头边缘形成光晕效果，
温暖、充满希望的氛围，5秒时长
```

## 三、Prompt Engineering通用原则

### 3.1 核心方法论

**1. 迭代优化**
- 不要指望一次写好
- 像搭积木一样逐步优化
- 每次只改变一个变量，对比效果

**2. 具体优于抽象**
| 抽象 ❌ | 具体 ✅ |
|---------|---------|
| 踱步 | 走到画面右侧 |
| 好看的光线 | 侧光从45度角照射，形成明暗对比 |
| 精致的细节 | 金属表面有细密划痕和氧化斑点 |
| 温暖的氛围 | 暖金色调，橙黄色光线，柔和阴影 |

**3. 分步指令**
- 复杂场景拆分为多步骤
- 按时间顺序或空间顺序描述
- 使用"首先...然后...最后..."

**4. 专业术语**
- 摄影/电影术语识别度更高
- 光线：侧光、逆光、轮廓光、体积光
- 镜头：广角、微距、低机位、高角度
- 构图：三分法、引导线、框架构图

### 3.2 A/B测试方法

1. **固定80%的描述词**（控制变量）
2. **改变20%的变量**（光线/角度/氛围）
3. **对比结果**，记录最佳组合
4. **形成个人词库**

**测试记录模板**：
```
测试日期：2026-03-31
固定词：[风格]皮克斯3D，[主体]机器人，[质量]8K
变量：光线
- A版：金色逆光 → 结果：太强烈
- B版：柔光侧光 → 结果：✅ 最佳
- C版：顶光 → 结果：太压抑
结论：此场景适合柔光侧光
```

```

```

**技术规范**：
```
纯白背景，角色居中，全身完整显示，
无阴影，无环境元素，
技术设计图风格，清晰轮廓，
正面/侧面/背面视角标注
```

### 3.2 三视图一致性技巧

1. **固定描述词**（95%相同）：
   - 风格、材质、核心特征保持一致
   - 只改变视角描述

2. **使用参考图**：
   - 正视图 → 作为侧视图的参考图
   - 保持种子值一致

高清8K

**侧视图**：
