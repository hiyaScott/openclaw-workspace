# 初中教材目录页面制作规范

## 项目概述

为 Scott 制作初中数学/物理的交互课件目录导航页面，采用赛博朋克视觉风格，支持游戏化交互课件链接。

## 版本体系

### 数学
- **版本**: 沪教版（上海教育出版社）· 五四制
- **现行教材**: 2024新版（2024年秋季起启用）
- **特点**: 跨学期连续编号（第1章→第28章），六年级为"预备班"

### 物理
- **版本**: 沪科版（上海科学技术出版社）· 五四制 · 2024年版
- **实施时间**: 2025学年起，八年级和九年级全面启用
- **特点**: 上海物理从**八年级**开始，每册独立编号（第1章→第17章）
- **重要**: 不是沪教版！2024新版已切换为沪科版

## 核心设计模式

### 1. 新旧衔接区块（数学特有，视情况保留）

2024新版数学将旧版六上的「数的整除」「分数」下放至小学五年级，但旧版小学教材未系统覆盖，造成小升初知识断层。

**设计**: 
- 在页面顶部设置独立的「新旧衔接」区块（purple风格）
- 保留旧版课件链接作为「小升初知识断层补丁」
- 说明文字解释衔接必要性
- **注意**: 若新版教材已完全覆盖，可移除衔接区块

### 2. 主课程体系

**数学**: 跨学期连续编号（第1章→第28章），不重置
**物理**: 每册内部独立编号（八上第1-5章，八下第6-9章，九上第10-13章，九下第14-17章）

**编号规范**:
- 数学: `第{X}章 {章节名}`（X为1-28的连续编号）
- 物理: `第{X}章 {章节名}`（X为1-17的连续编号，跨册不重置）
- 序言/导入: 可用"序言"或"第0章"（如物理「踏上物理学奇妙旅途」）

### 3. 课件链接路径

```
courseware-{subject}/grade{6-9}-sem{1-2}-ch{xx}/
    ├── tutorial.html   # 教程/学案
    └── index.html      # 交互游戏
```

**示例**:
- `courseware-math/grade6-sem1-ch01/` — 六年级上第1章（有理数）
- `courseware-physics/grade8-sem1-ch01/` — 八年级上第1章（测量）

### 4. 状态标签

| 状态 | CSS类 | 用途 |
|------|-------|------|
| 已完成 | `.ready` | 已有课件，可点击 |
| 待制作 | `.pending` | 目录已确认，课件未制作 |
| 待确认 | `.pending` + 文字标注 | 目录待实体课本验证 |
| 迁移中 | `.migrated` | 旧课件需按新教材调整 |

## 视觉风格规范

### CSS变量
```css
:root {
    --neon-pink: #ff00ff;
    --neon-cyan: #00ffff;
    --neon-green: #39ff14;
    --neon-yellow: #ffff00;
    --neon-amber: #f59e0b;
    --neon-purple: #9d00ff;
    --dark: #0a0a0a;
}
```

### 字体
- 主字体: `'Noto Sans SC', 'Share Tech Mono', monospace`
- 标题字重: 900
- 正文字重: 400

### 特效
- CRT扫描线: `body::before` + `repeating-linear-gradient`
- 故障背景: `.glitch-bg` + `bgShift` 动画
- 卡片悬停: `translateY(-5px)` + 霓虹阴影

## 发布检查流程

```
1. 本地验证 → HTML/CSS/JS无语法错误
2. git commit → 规范提交信息（vX.Y: 变更说明）
3. git push → 确认推送成功
4. 等待缓存 → GitHub Pages通常1-5分钟刷新
5. 线上QA → curl/kimi_fetch验证内容
6. 效果确认 → 浏览器访问确认渲染正常
```

**提交信息模板**:
```
v{major}.{minor}: {变更说明}

- 修改文件1: {具体变更}
- 修改文件2: {具体变更}
```

## 关键规则

1. **确认版本优先**: 做任何课件前，必须先确认出版社、版本年份、具体目录
2. **用户/实体课本为唯一来源**: 不依赖网络搜索的二手目录（易混入其他版本）
3. **数学物理分开管理**: 数学沪教版、物理沪科版，版本不同，不能混用
4. **编号不重置**: 数学第1-28章连续编号；物理第1-17章连续编号（跨册不重置）
5. **物理从八年级开始**: 六年级七年级没有物理课
