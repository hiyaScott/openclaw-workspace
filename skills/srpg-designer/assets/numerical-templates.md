# SRPG 数值表模板使用指南

本文档说明如何使用 Excel/Google Sheets 进行战棋数值设计。

---

## 📊 模板一：职业基础属性表

### 用途
定义各职业的初始属性和成长特性。

### 表格结构

```
| 字段 | 说明 | 示例值 |
|------|------|--------|
| 职业ID | 唯一标识 | WARRIOR |
| 职业名称 | 显示名称 | 战士 |
| 初始HP | 1级生命值 | 28 |
| 初始攻击 | 1级攻击力 | 12 |
| 初始防御 | 1级防御力 | 8 |
| 初始速度 | 1级速度 | 8 |
| 初始技巧 | 1级技巧 | 10 |
| 初始幸运 | 1级幸运 | 8 |
| 移动力 | 每回合移动格数 | 5 |
| 攻击射程 | 攻击距离 | 1 |
| HP成长率 | 每次升级概率 | 0.9 |
| 攻击成长率 | 每次升级概率 | 0.8 |
| ... | ... | ... |
```

### 公式示例

**等级属性计算**:
```excel
=初始值 + SUMPRODUCT(
    (RANDBETWEEN(1,100)<=成长率*100) 
    对于每次升级
)
```

**简化版 (固定成长)**:
```excel
=初始值 + INT((等级-1) * 成长率)
```

## 📊 模板二：伤害公式验证表

### 用途
验证不同攻防属性下的伤害输出。

### 表格结构

```
| 攻击方 | 攻击力 | 技巧 | 防御方 | 防御力 | 速度 | 基础伤害 | 命中 | 期望伤害 |
|--------|--------|------|--------|--------|------|----------|------|----------|
| 战士 | 50 | 15 | 骑士 | 40 | 10 | =公式 | =公式 | =公式 |
```

### 公式实现

#### 减法公式
```excel
=MAX(1, 攻击力 - 防御力)
```

#### 百分比减伤公式
```excel
=攻击力 * (1 - 防御力/(防御力+100))
```

#### 混合公式
```excel
=MAX(1, 攻击力-防御力*0.5) * (1 - 防御力/(防御力+100)*0.5)
```

#### 命中率计算
```excel
=MAX(5, MIN(95, 85 + (技巧-速度)/2))
```

#### 期望伤害 (考虑命中)
```excel
=基础伤害 * 命中率/100
```

## 📊 模板三：职业克制矩阵

### 用途
可视化职业克制关系和胜率预期。

### 表格结构

```
| 攻击\防御 | 战士 | 骑士 | 弓手 | 法师 | 骑兵 |
|-----------|------|------|------|------|------|
| 战士 | 50% | 45% | 55% | 60% | 70% |
| 骑士 | 55% | 50% | 60% | 45% | 40% |
| ... | ... | ... | ... | ... | ... |
```

### 条件格式

- **绿色 (55%+)**: 优势对局
- **黄色 (45-55%)**: 均势对局
- **红色 (<45%)**: 劣势对局

## 📊 模板四：TTK (击杀回合) 计算表

### 用途
计算击杀期望回合数，验证战斗节奏。

### 表格结构

```
| 攻击方 | 防御方 | 单次伤害 | 攻击频率 | 击杀回合 |
|--------|--------|----------|----------|----------|
| 战士 | 弓手 | 35 | 1 | =CEILING(弓手HP/35) |
| 弓手 | 战士 | 15 | 1 | =CEILING(战士HP/15) |
```

### 目标TTK参考

| 单位类型 | 被同级击杀 | 被克制击杀 |
|----------|------------|------------|
| 脆皮 | 2-3回合 | 1-2回合 |
| 标准 | 3-4回合 | 2-3回合 |
| 坦克 | 4-6回合 | 2-4回合 |

## 📊 模板五：技能平衡表

### 用途
规划技能威力、冷却和效果。

### 表格结构

```
| 技能ID | 名称 | 威力系数 | 冷却 | 范围 | 效果 | DPS等效 |
|--------|------|----------|------|------|------|---------|
| SKILL_001 | 重击 | 1.5 | 2 | 单体 | 无 | =1.5/3 |
| SKILL_002 | 旋风斩 | 0.8 | 3 | 3格 | 无 | =0.8*3/4 |
```

### DPS等效公式

```excel
=威力系数 * 目标数 / (冷却回合 + 1)
```

## 📊 模板六：关卡难度曲线

### 用途
规划关卡难度随进度的变化。

### 表格结构

```
| 关卡ID | 推荐等级 | 敌人数量 | 敌人强度 | 推荐战力 | 预期通关时间 |
|--------|----------|----------|----------|----------|--------------|
| 1-1 | 1 | 3 | 80% | 100 | 3min |
| 1-2 | 2 | 4 | 85% | 110 | 4min |
| ... | ... | ... | ... | ... | ... |
```

### 难度公式

```excel
推荐战力 = 基准战力 * (1 + 关卡序号 * 难度增长率)
```

## 🛠️ Excel 高级技巧

### 1. 数据验证

限制输入范围，防止错误数据:
```
数据 → 数据验证 → 允许: 小数 → 介于 0 和 1
```

### 2. 条件格式

可视化数值问题:
```
开始 → 条件格式 → 色阶/数据条
```

### 3. 模拟运算表

批量测试不同参数:
```
数据 → 模拟分析 → 模拟运算表
```

### 4. 图表可视化

创建属性雷达图:
```
插入 → 图表 → 雷达图
```

## 💡 使用流程

1. **初版设计**: 在职业数值表中填写初始值
2. **公式验证**: 使用伤害公式表验证输出
3. **平衡检查**: 查看克制矩阵，调整数值
4. **TTK验证**: 确保击杀回合符合预期
5. **迭代优化**: 根据测试结果调整，保留历史版本
