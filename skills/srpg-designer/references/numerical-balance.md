# 战棋数值平衡 (Numerical Balance)

## 战棋数值特点

### 与其他游戏类型的差异

```
对比:

MMORPG:
├─ 连续战斗，数值平滑
├─ 强调DPS/HPS
└─ 成长感重要

卡牌游戏:
├─ 离散战斗，随机抽牌
├─ 强调牌效和资源管理
└─ 构筑感重要

战棋SRPG:
├─ 离散战斗，每关独立
├─ 强调位置/策略/单位搭配
├─ 单个单位价值高 (permadeath)
└─ 策略验证 > 数值验证
```

### 核心平衡原则

```
策略优先:
- 策略正确可以越级挑战
- 策略错误会被同级击败
- 数值提供容错空间而非决定性优势

单位价值:
- 每个单位都珍贵 (permadeath设计)
- 损失评估是策略一部分
-  recovery成本高昂
```

## 基础数值公式

### 伤害公式设计

#### 1. 减法公式 (日式SRPG主流)

```
伤害 = max(1, 攻击力 - 防御力) × 克制系数 × 其他系数

示例:
攻击力: 50
防御力: 30
克制系数: 1.3 (兵种克制)
暴击: 1.5

伤害 = (50 - 30) × 1.3 × 1.5 = 39

优点:
├─ 直观易懂
├─ 防御价值明确
└─ 低攻打高防有意义

缺点:
├─ 攻防差过大时伤害固化
├─ 需要精心平衡数值范围
└─ 容易出现不破防情况
```

#### 2. 百分比减伤公式 (更平滑)

```
伤害 = 攻击力 × (1 - 减伤率)

其中:
减伤率 = 防御力 / (防御力 + K)

K为设计常数，通常取100或根据等级调整:
├─ K = 100: 适合低数值游戏
├─ K = 等级×10: 适合等级成长游戏
└─ K = 护甲类型基准值: 适合装备驱动游戏

示例:
攻击力: 100
防御力: 50
K = 100

减伤率 = 50 / (50 + 100) = 33.3%
伤害 = 100 × (1 - 0.333) = 67

优点:
├─ 平滑递减，无零伤害问题
├─ 攻防价值相对平衡
├─ 易扩展多维度防御(物理/魔法/真实)

缺点:
├─ 不够直观，玩家难理解
├─ 防御收益递减，堆叠收益降低
└─ 需要调试K值平衡
```

#### 3. 混合公式 (推荐)

```
基础伤害 = max(1, 攻击力 - 防御力×0.5)
减伤率 = 防御力 / (防御力 + 100)
最终伤害 = 基础伤害 × (1 - 减伤率×0.5) × 克制系数

设计思路:
- 保留减法公式的直观性
- 加入百分比减伤的平滑性
- 系数0.5可调整，控制防御价值
```

#### 4. 伤害波动设计

```
伤害波动范围:
├─ 固定值: 无波动，确定性强
├─ ±10%: 轻微随机，保留惊喜
├─ ±20%: 中等随机，低属性有机会逆袭
└─ ±30%: 高随机，策略权重降低

推荐设置:
伤害 = 计算伤害 × (0.9 + random(0, 0.2))
即 ±10% 波动
```

### 命中率与回避率公式

#### 基础命中率公式

```
命中率 = min(上限, max(下限, 基础命中 + 技巧修正 - 回避修正))

其中:
基础命中 = 武器基础命中 (通常80-95)
技巧修正 = (攻击方技巧 - 防御方速度) / 2
回避修正 = 地形闪避 + 状态闪避

标准参数:
├─ 上限: 95% (保留意外可能)
├─ 下限: 5% (保留希望)
├─ 技巧系数: 每点技巧差提供0.5%命中
└─ 速度系数: 每点速度差提供0.5%回避

示例:
攻击方技巧: 15
防御方速度: 12
武器命中: 85%
地形闪避: 10%

命中率 = 85 + (15-12)/2 - 10 = 85 + 1.5 - 10 = 76.5%
```

#### 回避率公式变体

```
变体1 - 纯减法:
回避率 = 防御方速度 - 攻击方技巧 + 地形加成

变体2 - 百分比:
回避率 = 速度 / (速度 + 100) × 100%

变体3 - 综合公式:
命中判定 = 随机数(1-100) ≤ (技巧×2 - 速度 + 基础命中)

设计建议:
- 保持命中/回避在合理范围 (30%-95%)
- 速度属性要有价值但不过度
- 高命中职业特色要明显
```

#### 距离对命中的影响

```
近战武器:
├─ 1格: 100%命中系数
└─ 无距离惩罚

远程武器:
├─ 最优射程: 100%命中
├─ 每超出一格: -5%至-10%命中
├─ 最小射程限制: 过近无法攻击
└─ 最大射程限制: 超出无法攻击

法术攻击:
├─ 通常无视距离惩罚
├─ 但可能有最小射程限制
└─ 或特定地形阻挡
```

### 暴击率与暴击伤害设计

#### 暴击率公式

```
暴击率 = max(0, min(上限, (技巧 - 幸运) / 暴击系数 + 武器暴击))

标准参数:
├─ 暴击系数: 通常5 (每5点技巧差提供1%暴击)
├─ 基础暴击上限: 30-50%
├─ 武器暴击: 通常0-15%
└─ 职业修正: 刺客/忍者类职业可能有+10-20%加成

示例:
攻击方技巧: 20
防御方幸运: 10
武器暴击: 10%
暴击系数: 5

暴击率 = (20-10)/5 + 10 = 2 + 10 = 12%
```

#### 暴击伤害公式

```
暴击伤害 = 基础伤害 × 暴击倍率

暴击倍率设置:
├─ 标准: 1.5倍 (50%额外伤害)
├─ 高暴击: 2.0倍 (火纹传统)
├─ 低暴击高伤害: 2.5-3.0倍
└─ 可配合: 暴击伤害加成装备/技能

设计建议:
- 暴击是"惊喜"机制，不是主要输出手段
- 基础暴击率控制在3-10%
- 暴击抗性作为坦克属性有价值
```

#### 暴击抗性设计

```
暴击抗性 = 减少被暴击的概率

实现方式:
├─ 幸运属性: 每点幸运降低被暴击率0.2%
├─ 装备特效: "受到暴击率-20%"
├─ 技能效果: 持续X回合免疫暴击
└─ 职业特性: 重甲职业天生-30%被暴击率

平衡要点:
- 暴击抗性不应完全消除暴击
- 保留5%最低暴击率作为"奇迹"可能
- 坦克职业通过暴击抗性体现硬度
```

### 移动力与地图尺寸关系

#### 移动力基准值

```
移动力(格子数):
├─ 重甲/步兵: 3-4格
├─ 标准步兵: 4-5格
├─ 轻甲/斥候: 5-6格
├─ 骑兵: 6-8格 (通常直线移动)
├─ 飞行: 5-7格 (无视地形)
└─ 特殊: 传送/瞬移 (1-2回合冷却)

移动类型:
├─ 步行: 正常消耗
├─ 骑兵: 森林/山地消耗+1
├─ 飞行: 无视所有地形
└─ 游泳/水上: 水域正常，陆地受限
```

#### 地图尺寸设计

```
地图尺寸 = 根据单局时长和策略深度设计

小型地图 (10×10 ~ 15×15):
├─ 单局时长: 5-10分钟
├─ 单位数量: 3-5个
├─ 接触速度: 1-2回合
└─ 适用: 教学关、日常任务、PVP快速对局

中型地图 (15×15 ~ 20×20):
├─ 单局时长: 15-20分钟
├─ 单位数量: 5-8个
├─ 接触速度: 2-3回合
└─ 适用: 主线关卡、活动关卡

大型地图 (20×20 ~ 30×30):
├─ 单局时长: 30-45分钟
├─ 单位数量: 8-12个
├─ 接触速度: 3-5回合
└─ 适用: BOSS战、剧情关、挑战关卡

超大型地图 (30×30+):
├─ 单局时长: 45分钟+
├─ 单位数量: 10+个
├─ 可能有分兵/多路线设计
└─ 适用: 特殊战役、沙盒模式
```

#### 移动力与地图的黄金比例

```
核心公式:
地图直径 = 平均移动力 × 接触回合数 × 2

接触回合数设计:
├─ 快速交战: 2回合接触
├─ 标准交战: 3回合接触
├─ 慢速交战: 4-5回合接触

示例:
平均移动力 = 5格
期望接触回合 = 3

推荐地图直径 = 5 × 3 × 2 = 30格
即 15×15 到 20×20 的地图

设计考虑:
- 考虑地形消耗 (实际移动距离更短)
- 考虑出生点位置 (不一定对角)
- 考虑射程因素 (远程可提前交战)
```

#### 射程与移动力的平衡

```
射程(格子数):
├─ 近战: 1格
├─ 长柄: 1-2格 (可隔一格攻击)
├─ 短程远程: 2格
├─ 中程远程: 3格
├─ 长程远程: 4-5格
└─ 超远程/攻城: 6-10格

平衡公式:
有效威胁范围 = 移动力 + 射程

标准单位:
├─ 近战: 5移动 + 1射程 = 6威胁范围
├─ 骑兵: 7移动 + 1射程 = 8威胁范围
├─ 弓手: 4移动 + 3射程 = 7威胁范围
└─ 法师: 4移动 + 2射程 = 6威胁范围

设计原则:
- 威胁范围差距控制在±2格内
- 骑兵威胁范围最大但受限地形
- 远程单位低移动力是平衡手段
```

## 职业平衡设计

### 职业三角克制关系

```
基础三角 (火纹模式):

        剑/步兵
       /        \
      /          \
     /            \
斧/重甲 ─────── 枪/骑兵

克制关系:
├─ 剑克斧 (优势方+20%伤害)
├─ 斧克枪 (优势方+20%伤害)
├─ 枪克剑 (优势方+20%伤害)
└─ 被克方-20%伤害

扩展三角 (加入远程):

        骑兵
       /    \
      /      \
     /        \
步兵 ───────── 远程
     \        /
      \      /
       \    /
        法师

克制关系:
├─ 骑兵克远程 (快速接近)
├─ 远程克法师 (法师通常低防)
├─ 法师克骑兵 (魔法无视防御)
└─ 步兵克制关系较弱，作为基准
```

### 属性成长曲线设计

#### 成长率系统

```
每次升级属性成长 = 基础值 + 成长率判定

成长率判定:
├─ 若随机数(0-100) ≤ 成长率: 属性+1
├─ 部分属性可能有+2/+3的额外成长
└─ 部分职业有保底成长

成长类型分类:
├─ 早熟型: 前期成长率高，后期放缓
├─ 晚成型: 前期成长率低，后期爆发
├─ 均衡型: 稳定成长
└─ 特化型: 某属性极高，其他较低

示例成长率表:
| 职业 | HP | 攻击 | 防御 | 技巧 | 速度 | 幸运 |
|------|----|------|------|------|------|------|
| 战士 | 90 | 80   | 60   | 50   | 50   | 40   |
| 骑士 | 85 | 65   | 80   | 45   | 35   | 50   |
| 弓手 | 65 | 75   | 35   | 70   | 60   | 60   |
| 法师 | 55 | 85   | 30   | 65   | 55   | 55   |
```

#### 属性上限设计

```
属性上限控制:
├─ 保证后期不会无限成长
├─ 不同职业上限不同，体现职业特色
└─ 可通过道具/转职突破上限

上限示例 (满级60级预期上限):
| 职业 | HP  | 攻击 | 防御 | 技巧 | 速度 |
|------|-----|------|------|------|------|
| 战士 | 200 | 150  | 120  | 100  | 100  |
| 骑士 | 220 | 130  | 150  | 90   | 80   |
| 弓手 | 160 | 140  | 80   | 140  | 120  |
| 法师 | 140 | 160  | 70   | 130  | 110  |
```

### 技能冷却与威力平衡

#### 技能威力基准

```
威力系数 = 技能伤害 / 普通攻击伤害

标准威力分级:
├─ 小技能 (无冷却): 0.8-1.0倍
├─ 常规技能 (1回合CD): 1.2-1.5倍
├─ 强力技能 (2-3回合CD): 1.8-2.5倍
├─ 终极技能 (4+回合CD): 3.0-5.0倍
├─ AOE技能: 系数×0.5-0.7 (范围惩罚)
└─ 特殊效果技能: 系数-0.2至-0.5

DPS等效公式:
实际DPS = 技能威力 / (冷却回合 + 1)

示例:
普通攻击: 1.0倍，每回合1次
强力技能: 2.0倍，2回合冷却

普通DPS = 1.0
技能DPS = 2.0 / 3 = 0.67 (略低，但爆发更高)
```

#### 冷却回合设计原则

```
冷却设计考量:

1回合冷却 (几乎每回合可用):
├─ 作为"强化普攻"使用
├─ 威力略高于普攻
└─ 用于维持职业特色输出

2-3回合冷却 (常规技能):
├─ 主要输出手段
├─ 需要规划使用时机
└─ 通常有额外效果(位移/控制)

4+回合冷却 (终极技能):
├─ 每局使用1-2次
├─ 决定战局的技能
├─ 威力强大或有特殊效果
└─ 使用时机是策略核心

冷却重置机制:
├─ 击杀重置: 鼓励连杀
├─ 特定条件重置: 策略配合
└─ 开局冷却: 防止开场爆发
```

#### 技能效果与数值平衡

```
效果价值换算:

控制效果 (眩晕/冻结/睡眠):
├─ 1回合控制 ≈ 2倍伤害价值
├─ 被控制目标无法行动 + 易受伤
└─ 通常配合较长冷却

位移效果 (击退/拉近/换位):
├─ 1格位移 ≈ 0.5倍伤害价值
├─ 地形杀/控制集火的价值
└─ 策略价值高于数值价值

增益/减益:
├─ +20%攻击 ≈ 1.2倍伤害
├─ -20%防御 ≈ 1.25倍伤害(团队收益)
└─ 持续回合数影响总价值

治疗:
├─ 治疗量 = 伤害量 × 0.8 (治疗有边际效应)
├─ 群体治疗 = 单体治疗 × 0.6
└─ 持续恢复 = 即时治疗 × 0.7
```

## 战斗平衡

### TTK (Time To Kill) 控制

```
击杀期望回合数:

脆皮单位:
├─ 被同级攻击: 2-3次
├─ 被克制攻击: 1-2次
└─ 策略意义: 需要保护

坦克单位:
├─ 被同级攻击: 4-6次
├─ 被克制攻击: 2-3次
└─ 策略意义: 前线抗压

设计目的:
- 战斗不会太快结束
- 每个单位都有存在感
- 失误有挽回空间
```

### 职业平衡

```
三角平衡:

剑士 vs 枪兵 vs 骑兵

克制效果:
├─ 克制方: +20-30% 伤害
├─ 被克方: -20-30% 伤害
└─ 平衡: 任何职业都有优劣势

非克制战斗:
├─ 职业特色发挥作用
├─ 技能/装备影响更大
└─ 策略选择更重要
```

## 养成与关卡匹配

### 难度曲线设计

```
推荐战力系统:

关卡难度 = 推荐等级 × 基准属性

实际体验:
├─ 战力达标: 适当策略可通过
├─ 战力超标20%: 数值碾压
├─ 战力不足20%: 需要精密策略
└─ 战力不足50%: 极难/不可能

设计目的:
- 给玩家成长感
- 但策略仍能弥补数值差距
- 不同付费层级都有挑战
```

### 属性验证节奏

```
成长验证:

早期 (1-10级):
├─ 属性差异小
├─ 策略影响大
└─ 教学关卡为主

中期 (10-30级):
├─ 属性差异显现
├─ 职业特色形成
└─ 策略配合数值

后期 (30级+):
├─ 属性差异大
├─ 养成深度体现
└─ 高难度策略挑战
```

## 手游SRPG数值规划

### 长线养成数值

```
养成线设计:

角色等级:
├─ 满级: 60-80级
├─ 前期快 (1-40)
├─ 后期慢 (40-60)
└─ 极慢 (60+)

装备强化:
├─ 等级: +1 到 +15/+20
├─ 前期成功率100%
├─ 后期成功率递减
└─ 失败惩罚 (降级/破碎)

技能升级:
├─ 等级: 1-5级或1-10级
├─ 材料需求递增
└─ 效果提升非线性
```

### 付费与免费平衡

```
战力差距控制:

同等级对比:
├─ 免费玩家: 基准战力100%
├─ 月卡玩家: 110-120%
├─ 中氪玩家: 130-150%
└─ 重氪玩家: 180-200%

设计原则:
- 免费玩家能通关主线
- 付费玩家更轻松/更快
- 策略可以弥补付费差距
- 高难内容需要策略+数值

时间换算:
├─ 1元 ≈ 10-15分钟游戏时间
├─ 月卡性价比最高
└─ 重氪边际效应递减
```

## 数值调试方法

### 战斗模拟
