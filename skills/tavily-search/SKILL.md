# Tavily Search - AI 智能搜索

## 功能概述

Tavily Search 是专门为 AI Agent 设计的搜索工具，相比传统搜索引擎：

- ✅ **为 LLM 优化** - 返回结构化、干净的结果
- ✅ **广告过滤** - 自动过滤推广内容
- ✅ **信息聚合** - 自动总结多个来源
- ✅ **国内镜像** - 支持国内网络访问

## 与 Brave Search 对比

| 特性 | Brave Search | Tavily Search |
|------|--------------|---------------|
| 设计目标 | 通用隐私搜索 | 专门为 AI 优化 |
| 结果格式 | 标准网页 | 结构化摘要 |
| 广告过滤 | 基础 | 深度优化 |
| 上下文理解 | 一般 | 专为 LLM 设计 |
| 国内访问 | 需要 API key | 有国内镜像源 |
| 多源聚合 | 无 | 自动聚合多个来源 |

## 核心优势

### 1. 搜索结果优化

**传统搜索结果**:
```
标题1 - 链接1
标题2 - 链接2
...（10个蓝链）
```

**Tavily 搜索结果**:
```
📊 综合摘要
基于5个来源的总结：...

📰 关键信息点
- 要点1（来源A, B）
- 要点2（来源C, D）
- 要点3（来源A, E）

🔗 参考来源
1. [标题A](链接A) - 可信度: 高
2. [标题B](链接B) - 可信度: 中
...
```

### 2. 深度研究模式

```
搜索: "2024年AI视频生成技术发展"

Tavily 会:
✓ 找到10+相关来源
✓ 按时间线整理发展脉络
✓ 对比不同产品的技术路线
✓ 提取关键数据和评价
✓ 生成结构化的研究报告
```

### 3. 实时信息获取

- 股票价格（实时）
- 新闻事件（最新）
- 学术论文（最新发表）
- 产品发布（最新消息）

## 使用场景

### 场景1: 快速事实核查
```
问: "OpenAI 最新发布的模型是什么？"
→ Tavily 搜索 → 返回最新准确信息
```

### 场景2: 深度行业研究
```
问: "分析2024年跨境电商市场的主要趋势"
→ Tavily 深度搜索 → 多源信息聚合 → 结构化报告
```

### 场景3: 技术文档查询
```
问: "Python 3.12 的新特性"
→ Tavily 搜索官方文档 + 社区文章 → 整理特性列表
```

## 使用方法

### 基础搜索
```
搜索: "关键字"
tavily: "查询内容"
```

### 高级搜索
```
深度搜索: "主题"        # 启用研究模式
搜索最新: "主题"        # 优先最新结果
搜索中文: "主题"        # 优先中文来源
```

### 参数配置
```
设置搜索深度: 标准/深度/全面
设置时间范围: 最近一天/一周/一月/一年
设置来源类型: 新闻/学术/博客/全部
```

## 配置说明

### API Key 设置
```bash
# 方式1: 环境变量
export TAVILY_API_KEY=your-api-key

# 方式2: OpenClaw 配置
openclaw configure --section tavily
```

### 国内镜像配置
```bash
# 自动检测，无需额外配置
# 如需要手动指定:
export TAVILY_ENDPOINT=https://api.tavily.cn
```

## 注意事项

1. **API 限制**: 免费版有每日调用限制
2. **隐私**: Tavily 不记录个人搜索历史
3. **准确性**: 仍需人工核实关键信息
4. **引用**: 使用 Tavily 结果时建议保留来源链接

## 故障排除

| 问题 | 解决方案 |
|------|----------|
| 搜索无结果 | 检查 API key 是否有效 |
| 结果为空 | 尝试更通用的关键词 |
| 访问超时 | 检查网络连接，或启用国内镜像 |
