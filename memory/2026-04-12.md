

## Max Qian Portfolio Website - Avatar Interaction Development (2026-04-12)

### Goal
Build a personal portfolio website for Max Qian (11-year-old 5th grader) with split-screen Player/Creator avatar interaction inspired by adhamdannaway.com.

### Key Technical Challenges Solved

#### 1. Clip-path Area Transition (NOT opacity fade)
- **Correct approach**: Two overlapping images with clip-path controlling visible area ratio
- **Default**: Each image shows 50% (Player left half, Creator right half)
- **Interaction**: Mouse movement changes clip-path percentages (0-100% visible area)
- **Code**: `clip-path: inset(0 X% 0 0)` for Player, `clip-path: inset(0 0 0 X%)` for Creator

#### 2. Alpha Channel Handling
- Both Player and Creator images have transparent backgrounds
- Processed with Python PIL to preserve RGBA channels
- Exported as WebP format (supports transparency, smaller file size)
- Final sizes: Player 57KB, Creator 91KB (down from 3-4MB originals)

#### 3. Layout Hierarchy (Background Text Behind Avatar)
```
z-index layers:
- z:1   Background large text "Player" / "<Creator>"
- z:5   Avatar images (transparent background)
- z:10  Foreground descriptive text
```
Effect: Background text visible through transparent avatar areas

#### 4. Image Sizing Fix
- **Problem**: `height: 100%` was cropping image width
- **Solution**: Use `max-height: 100%` + `max-width: 100%` with `object-fit: contain`
- Result: Full image displayed, clip-path only controls which half is visible

### Final Dimensions
- Avatar container: 50vw × 70vh (responsive)
- Image resolution: 800×610px (compressed from 2343×1789)
- Total image payload: ~148KB

### Layout Revision (2026-04-13)

#### New Z-Index Hierarchy
```
z:1  - Player / <Creator> large text (background, partially hidden by avatar)
z:5  - Avatar images (foreground, covers the text)
z:10 - Description text at bottom (Game Player / Game Creator)
```

#### Visual Structure
- **Top layer**: Avatar images with clip-path split effect
- **Middle**: Large "Player" and "<Creator>" text visible through transparent avatar edges
- **Bottom**: Short description labels positioned at bottom corners

#### Key Changes
- Moved background text from translucent (rgba) to solid black
- Increased font size for background text (clamp 80px-180px)
- Repositioned side descriptions to bottom (15% from bottom)
- Simplified description text to be shorter

### Lessons Learned
1. Clip-path area transition ≠ opacity fade (completely different visual effect)
2. WebP with alpha is ideal for transparent portraits (30-40% smaller than PNG)
3. Image sizing with CSS: `max-*` properties preserve aspect ratio better than fixed dimensions
4. z-index layering critical for "text behind avatar" effect
