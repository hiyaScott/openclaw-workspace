### Bug 1: ch1 导航按钮失效

**症状**: 点击 "下一单元" 无反应，内容不切换

**根因**: `let currentCh = 0;` 但第一个显示的是 `id="ch1"`
- `goTo(2)` 尝试隐藏 `ch0`（不存在）
- `ch1` 永远不会被隐藏，`ch2` 显示后两者重叠

**修复**: `currentCh = 0` → `currentCh = 1`

### Bug 2: ch1 内容顺序混乱

**症状**: 实验在例题/测验之后，但导航按钮在实验之上

**修复**: 重新排列 ch1 结构：
1. 概念卡片
2. 动画演示
3. **实验 1 + 实验 2**
4. 例题列表
5. 小测试
6. **导航按钮** ← 最底部

### Bug 3: 进度条错位

**症状**: ch1 显示时进度条第二格亮，应该第一格亮

**根因**: `updateProgress()` 直接用 `currentCh` 做索引（1→第二格），应减 1

**修复**: 添加 `const idx = currentCh - 1`

### Bug 4: ch2/ch3 实验在导航之下

**症状**: ch2/ch3 中 "实验" 和 "随堂测验" 出现在 "上一单元/下一单元" 按钮下方

**修复**: 将 ch2/ch3 的实验/测验内容全部移到 `btn-row` 之上
- ch2: 移动实验1、实验2、测验Q1-Q5
- ch3: 移动实验1、实验2、测验Q1-Q5

### Bug 5: ch3 HTML 标签断裂

**症状**: 移动 ch2 内容时，`<div class="card hidden" id="ch3">` 被拆成两半
```html
<!-- 错误 -->

  <div class="btn-row">...</div>id="ch3">
```

**修复**: 重新拼合标签

### 教训

2. **批量编辑 HTML 时要格外小心标签闭合**: 移动大块内容时容易拆断标签，修改后必须 grep 验证所有 `id="chX"` 标签完整性
