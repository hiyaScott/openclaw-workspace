#### 3. 剧本页面结构（4维度分析）
每个详细剧本页面包含：

1. **Concept 创意概念**
   - 核心命题
   - 创意来源
   - 情绪弧线设计
   - 爆款潜力分析

2. **Framework 结构框架**
   - 三幕结构表
   - 关键节拍设计
   - 场景设计表

3. **Detail 详细剧本**
   - 完整分镜脚本（16个镜头）
   - 每个镜头的画面/动作/声音描述
   - AI生成提示词（可灵/Runway/Sora适用）

4. **用户体验设计**
   - 观众心理预期管理
   - 传播设计（截图时刻/视频片段/金句）
   - 技术实现建议
