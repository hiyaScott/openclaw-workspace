### 六条硬性标准
1. **交互实验 ≥2 个/单元** — 可交互SVG动画，学生能"看见"物理过程
2. **例题 ≥3 个/单元，题目可见、答案展开** — `.q`始终可见放题目，`.a`点击展开放答案
3. **测试 ≥5 题/单元，选项答案匹配** — 概念辨析2题+情境应用2题+陷阱题1题
4. **反馈显示正常** — "✓ 正确！"不拼接任何选项文字
5. **有陷阱题/易错题** — 至少1题打破常见直觉错误
6. **有总结提示** — 核心区别/核心公式用高对比色强调

### 常见错误清单（禁止项）
- 题目藏在答案区
- 选项答案重复
- 反馈引用错误DOM
- 纯文字无交互
- 测试题太少（<5题）
- 无陷阱题

## 【硬件项目】妈妈计数器固件烧录 - ESP32-S3 (23:30-进行中)

### 项目背景
Scott 购买了 **微雪 ESP32-S3-Touch-LCD-1.54** 开发板，想要将"妈妈计数器"项目固件烧录进去。

### 开发板规格
- **型号**: 微雪 Waveshare ESP32-S3-Touch-LCD-1.54
- **芯片**: ESP32-S3-WROOM-1
- **屏幕**: 1.54寸 LCD，240×240 分辨率，ST7789 驱动
- **Flash**: 16MB
- **PSRAM**: 8MB
- **外设**: 双 I2S 数字麦克风、QMI8658 陀螺仪、板载扬声器、触摸
- **引脚**: TFT_CS=10, TFT_SCK=12, TFT_MOSI=11, TFT_DC=13, TFT_RST=9, TFT_BL=42, I2S_MIC_SCK=4, I2S_MIC_WS=5, I2S_MIC_SD=6, I2C_SDA=15, I2C_SCL=16, BUTTON_1=0, BUTTON_2=14

### 关键决策
1. **放弃 Arduino IDE**：国内下载 GitHub 资源极慢/频繁断线，Arduino IDE 几乎不可用
2. **改用 PlatformIO + VS Code**：下载体验更好，更适合长期使用
3. **板子定义**: 使用 `esp32-s3-devkitc-1`（原选的 `esp32-s3-devkitm-1` 不被 PlatformIO 识别报错）
4. **屏幕适配**: 从 GC9A01/360×360 改为 ST7789/240×240
5. **TFT_eSPI 配置**: 通过 `platformio.ini` 的 `build_flags` 直接注入 `User_Setup` 宏，避免手动修改库文件

### 创建的文件
- `/portfolio-blog/research/lab/mama-counter/MamaCounter_1.54_ST7789.ino` — 适配版完整代码
- `/portfolio-blog/research/lab/mama-counter/main.cpp` — 同上，供 PlatformIO 使用

### 技术配置 (platformio.ini)
```ini
[env:esp32-s3-devkitc-1]
platform = espressif32 @ 6.4.0
board = esp32-s3-devkitc-1
framework = arduino
monitor_speed = 115200
board_build.arduino.memory_type = qio_opi
board_build.partitions = default_16MB.csv
lib_deps = bodmer/TFT_eSPI @ ^2.5.0
build_flags =
    -DUSER_SETUP_LOADED=1
    -DST7789_DRIVER=1
    -DTFT_WIDTH=240
    -DTFT_HEIGHT=240
    -DTFT_MOSI=11
    -DTFT_SCLK=12
    -DTFT_CS=10
    -DTFT_DC=13
    -DTFT_RST=9
    -DLOAD_GLCD=1
    -DLOAD_FONT2=1
    -DLOAD_FONT4=1
    -DSPI_FREQUENCY=40000000
```
