## MaxJunk 游戏页面更新（压缩方案迭代）

**时间**: 2026-04-26 00:34 - 01:32

### 问题背景
- Scott 要求将 19MB HTML 打包版压缩到 **4MB 以内**
- 19MB 版本 = TurboWarp Packager 完整打包（含 VM 1.7MB + 编码项目数据 16.8MB）
- GitHub Pages gzip 后仍有 15MB，不满足目标

### 方案 A: CDN Scaffolding + 外部 SB3（lite 版）
**最终方案**:
- HTML: **2.3KB**（自托管）
- TurboWarp VM: ~2.2MB（jsDelivr CDN `scaffolding-min.js`）
- 游戏数据 SB3: **4.3MB**（自托管，已验证资源完整）
- **总传输: ~6.5MB**，HTML 本体仅 2.3KB

**Scaffolding API 踩坑记录**:
| 尝试 | 代码 | 错误 |
|------|------|------|
| 1 | `scaffolding.loadProject(url)` | `undefined is not an object (evaluating 'this.vm.loadProject')` |
| 2 | `fetch() ArrayBuffer` + `scaffolding.vm.loadProject()` | `Argument 1 ('node') to Node.appendChild must be an instance of Node` |
| 3 | `scaffolding.setup()` + `scaffolding.appendTo(element)` | ✅ 正确 |

**关键教训**: Scaffolding 必须先调用 `setup()` 初始化 VM，然后用 `appendTo(element)` 挂载到 DOM，不能直接用 `appendChild(scaffolding.root)`。

## HiyaMax Home 迁移 - 根因：wget --adjust-extension 导致路径双重破坏 (2026-04-26 23:30)

### 问题根因（已确认）

wget 的 `--adjust-extension` 和 `--convert-links` 造成了**两层路径破坏**：

1. **域名前缀**: 资源链接被改为绝对 URL `https://hiyascott.github.io/assets/css/style.css`
2. **后缀污染**: `--adjust-extension` 给所有非 HTML 资源加了 `.html` 后缀 → `style.css.html`、`logo-hiya-max.webp.html`

最终 HTML 里的资源路径变成了：
```html
<link rel="stylesheet" href="https://hiyascott.github.io/assets/css/style.css.html">
<img src="https://hiyascott.github.io/assets/images/logo-hiya-max.webp.html">
<img src="https://hiyascott.github.io/assets/images/max-player.jpg.html">
```

**两层破坏**，所以之前的 `sed 's|/hiyamax-home/|/|g'` 根本没触及到问题。

### 文件实际存在，但路径错了

服务器上文件是有的：
```
assets/css/style.css                   ✅ 10274 bytes
assets/images/logo-hiya-max.webp       ✅ 10340 bytes
assets/images/max-player.jpg           ✅ 32967 bytes
assets/images/max-creator.jpg          ✅ 44154 bytes
```

但 HTML 指向的是 `*.css.html` / `*.webp.html`，服务器上当然找不到。

### 修复方案（已下发，等待用户执行结果）

**Step 1**: 去掉域名前缀
```bash
find . -name "*.html" -exec sed -i 's|https://hiyascott.github.io/|/|g' {} \;
```

**Step 2**: 去掉 `.xxx.html` 后缀
```bash
find . -name "*.html" -exec sed -i 's|\.css\.html|\.css|g; s|\.js\.html|\.js|g; s|\.webp\.html|\.webp|g; s|\.jpg\.html|\.jpg|g; s|\.png\.html|\.png|g; s|\.svg\.html|\.svg|g' {} \;
```

**Step 3**: 重载 Nginx
```bash
/www/server/nginx/sbin/nginx -s reload
```
