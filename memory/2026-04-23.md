### 封面提取流程（标准化）

```bash
# 1. 复制 PDF 到 /tmp
# 2. 用 pdf-to-png-converter 提取首页
cd /tmp && node -e "
const { pdfToPng } = require('pdf-to-png-converter');
(async () => {
  const pngPages = await pdfToPng('/tmp/xxx.pdf', {
    outputFolder: '/tmp',
    outputFileMask: 'xxx',
    pagesToProcess: [1],
    viewportScale: 2.5,  // 高清
  });
})();
"
# 3. 复制到仓库
# 4. 创建 _books/xxx.md
# 5. git add → commit → push
```

**工具参数**：
- `pdf-to-png-converter` 已全局安装在 `/tmp/node_modules/`
- `viewportScale: 2.5` 输出 ~2400px 宽（高清）
- 横版 PDF（16:9 PPT）→ 2400x1350
- 竖版 PDF（A4）→ ~1500x2100
- 保持原始宽高比
