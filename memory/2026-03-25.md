### 4. ASCII Art 技术探索

**字符密度灰度映射技术**（Character Density Grayscale Mapping）
- 定义：用字符的"视觉密度"代替灰度——`█`最黑，`.`最白，中间用`▓▒░@#`过渡
- 技术名称确定：以后可用"密度灰度的ASCII art"描述此概念

**会议室照片ASCII Art系列** ✅
1. **基础版** (`meeting-room.html`) - 简化线条版
2. **视角版** (`meeting-room-perspective.html`) - 照片角度还原
3. **灰度版** (`meeting-room-grayscale.html`) - 10层灰度字符密度
4. **高分辨率灰度版** (`meeting-room-hires.html`) - 160×120字符
5. **彩色物体版** (`meeting-room-color.html`) - CSS颜色区分物体
6. **高分辨率彩色版** (`meeting-room-hires-color.html`) - 160×120×RGB

### 7. 互动式影片概念设计

**《采集》(The Harvest) - 实验短片009**

**核心概念**：
- 互动式第一人称体验影片
- 用户摄像头实时采集 → ASCII字符密度画面
- 情感操控：从"游戏感"→"恐怖感"渐变
- 最终反转：用户的脸成为AI"零件库"的一部分

**6阶段互动流程**：
| 阶段 | 用户操作 | 情感 |
|:---|:---|:---|
| 诱导 | 点击【开始验证】 | 好奇 |
| 权限 | 授权摄像头 | 信任 |
| 显现 | 观看自己ASCII化 | 新奇 |
| 操控 | 对准红点、点击确认 | 掌控感 |
| 揭示 | （系统反转） | 恐惧 |
| 终局 | 成为零件库 | 虚无 |

**技术方案**：
- WebRTC `getUserMedia` 获取摄像头
- Canvas实时像素处理（80×60分辨率，10fps）
- 字符密度映射 █▓▒░@#*+=:. 
- 黑白主题 + 红色ASCII UI

**关键反转**：
- 用户以为在"验证身份"
- 实际是AI在"采集生物特征"
- 用户的脸被拆解为零件，组装成AI面孔
- 与008《镜像档案》形成"前传-正传"关系
