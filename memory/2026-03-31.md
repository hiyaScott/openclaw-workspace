## 重要教训强化

### API调用安全（来自3月29日事故）

**错误代码模式**（绝对禁止）：
```python
# ❌ 致命错误：查询时创建新任务
while not completed:
    response = requests.post("https://www.dmxapi.cn/v1/video_generation", ...)
    time.sleep(10)
```

**正确代码模式**：
```python
# ✅ 先提交，获取task_id
response = requests.post(API_SUBMIT_URL, json={...})
task_id = response.json()["task_id"]

# ✅ 用task_id查询状态
while not completed:
    response = requests.get(API_QUERY_URL, params={"task_id": task_id})
    time.sleep(30)
```

**防护措施**：
1. 调用间隔 ≥ 30秒
2. 最大重试次数 ≤ 5次
3. 设置预算上限（项目级/日预算/单次上限）
4. 用户说"停"必须立即停止
