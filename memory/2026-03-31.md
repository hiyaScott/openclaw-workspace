## 【技术教训】海螺API首尾帧模式正确使用 (2026-03-31 15:40)

**任务**: 使用海螺API生成分镜3视频（首帧V7→尾帧V2）

### 第一次错误
**错误做法**: 使用单首帧模式
```python
{
  "model": "MiniMax-Hailuo-02",
  "image": "首帧V7的base64",  # ❌ 错误参数名
  "prompt": "...",
  "duration": 6
}
```

**问题**: 
- 使用了 `image` 参数（非标准）
- 没有指定 `last_frame_image`
- 生成的视频无法确保从首帧过渡到尾帧

### 第二次正确做法
**正确做法**: 使用首尾帧模式
```python
{
  "model": "MiniMax-Hailuo-02",
  "first_frame_image": "首帧V7的base64",  # ✅ 标准参数
  "last_frame_image": "尾帧V2的base64",   # ✅ 指定尾帧
  "prompt": "镜头缓慢推近...",
  "duration": 6,
  "resolution": "768P"
}
```

**生成结果**:
- 视频: `shot03_video_v2_hailuo_firstlast.mp4` (905KB, 768x768)
- 任务ID: 382520106279346
- 状态: ✅ 成功
- 视频时长: 6秒

**关键学习**:
1. 海螺API必须使用 `first_frame_image` 和 `last_frame_image` 参数
2. 不要使用 `image` 参数（非标准，行为不一致）
3. 首尾帧模式确保视频从首帧平滑过渡到尾帧
4. 分辨率可选: 768P 或 1080P（6秒时长）

**API调用流程**:
1. 提交: `POST /v1/video_generation` with first_frame_image + last_frame_image
2. 查询: `GET /v1/query/video_generation?task_id=xxx`
3. 下载: `GET /v1/files/retrieve?file_id=xxx&task_id=xxx`
