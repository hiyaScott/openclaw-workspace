- Canvas 粒子 sparkle 效果

**性能优化策略**:
- Canvas 替代 DOM 操作（GPU加速）
- requestAnimationFrame 节流（60fps锁定）
- 粒子数量上限100个
- 移动端自动禁用
- prefers-reduced-motion 无障碍支持
