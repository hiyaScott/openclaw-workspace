## 沪教版2024新版数学教材 重大变化（待决策）

**关键发现**:
2024新版沪教版五四制六年级上册目录完全变了：
- **旧版**: 数的整除 → 分数 → 比和比例 → 圆和扇形
- **新版**: 有理数 → 简单的代数式 → 一元一次方程 → 线段与角

**旧版"数的整除"和"分数"被删除**，下放到小学五年级。但小学旧版教材也没系统教这部分，造成小升初知识断层，多数学校会安排2-4周衔接补课。

**影响**:
- 用户现有两个课件基于旧版：
  - `grade6-sem1-ch01` — 数的整除"特工解谜"
  - `grade6-sem1-ch02` — 分数"分数特工"
- 如果跟进2024新版，这两个章节在新版中不存在了
- 上外附中（公立学校）统一使用沪教版2024新版教材

**待决策**:
- 选项A: 沿用旧版体系（课件保留，补全8-9年级旧版目录）
- 选项B: 跟进2024新版（六年级上需重写，课件可能需改定位）
