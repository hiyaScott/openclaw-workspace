## 2026-04-02 - cornup.com 网站修复记录

### 问题背景
Scott 删除了阿里云 CDN 的 `resource.cornup.com` 域名配置，导致所有网站访问异常。

### 诊断过程

#### 第一阶段：初步排查 (02:16-02:35)
- 发现 `resource.cornup.com` 返回 502 Bad Gateway
- 检查 CDN 配置：域名已重新添加，源站IP配置为 47.52.90.13
- 发现回源HOST未配置（显示"未开启"）
- 配置回源HOST为 `resource.cornup.com`

#### 第二阶段：服务器配置 (02:35-03:25)
- 发现磁盘满了（40G 100%），无法修改nginx配置
- 排查磁盘占用：
  - `/www/backup` 占 16G
  - `/www/server/panel` 占 7.5G
- 使用SSH连接服务器
- 发现nginx配置文件其实已经包含 `resource.cornup.com`（之前sed命令其实成功了）
- 重载nginx：`/etc/init.d/nginx reload`

#### 第三阶段：全面修复 (03:25-03:35)
- `resource.cornup.com` 恢复正常访问
- 但主站 `cornup.com` 和 `www.cornup.com` 返回 404
- 问题：DNS 缺少 `www` 和 `@` 记录
- 解决方案：
  1. 添加 `www` CNAME 记录指向 CDN
  2. 添加 `@` A 记录指向服务器IP 47.52.90.13

### 关键配置

#### DNS 配置（云解析DNS）
| 主机记录 | 记录类型 | 记录值 |
|---------|---------|--------|
| resource | CNAME | resource.cornup.com.w.cdngslb.com |
| www | CNAME | www.cornup.com.w.cdngslb.com |
| @ | A | 47.52.90.13 |

#### CDN 配置
- 域名：resource.cornup.com
- 源站：47.52.90.13
- 回源HOST：resource.cornup.com

#### Nginx 配置
```nginx
server_name www.cornup.com cornup.com resource.cornup.com;
```

### 问题根因
1. CDN域名删除后重新添加，回源HOST未配置
2. nginx server_name 缺少 resource.cornup.com
3. DNS 缺少 www 和 @ 记录

### 修复步骤总结
1. ✅ 配置CDN回源HOST
2. ✅ 修改nginx server_name 包含 resource.cornup.com
3. ✅ 重载nginx
4. ⏳ 添加DNS记录（www 和 @）
