## 【Bug修复】Game详情页重复Footer问题 (2026-04-18 19:45)

**问题**: Game详情页出现两个底部导航条（一个白色背景，一个深色背景）
**根因**: `game.html` 布局内嵌了完整footer HTML，同时继承的 `default` 布局又通过 `{% include footer.html %}` 渲染了一个footer

### 修复方案
移除 `game.html` 内嵌的footer HTML，只保留样式定义。Footer由 `default` 布局统一渲染。

### 变更
- `_layouts/game.html`：删除内嵌的 `<footer class="footer game-footer">...</footer>` HTML
- 保留 `.footer` 相关样式用于覆盖深色主题

### 提交
- `ef016d8` - Fix: remove duplicate footer from game detail page

### 教训
布局继承时要注意避免重复渲染。`default` 布局已包含footer时，子布局不应再定义完整footer HTML。
