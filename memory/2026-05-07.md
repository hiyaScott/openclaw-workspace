## Ch01 游戏卡死问题修复

**时间**: 5月7日 03:14 ~ 03:23
**问题**: 用户试玩Ch01重制版，第一关第三波次（BOSS限时2.5秒判断）答对后卡住不动，后续无法响应
**根因**: 
1. `glitchText` CSS 动画设置 `infinite alternate`，CPU高消耗导致浏览器卡顿
2. 过场动画 2.5 秒过长，用户等待期间以为卡死
3. BOSS答对后弹出 `intel-popup`（情报弹窗），但弹窗**没有自动关闭**，且关闭后不会继续下一题（`l1Answer` 中的判断逻辑 `if (!document.getElementById('intel-popup').classList.contains('active'))` 在弹窗关闭后条件满足，但 timeout 800ms 已过，不会触发下一题）

**修复方案**:
- 删除 `glitchText` 无限动画 keyframes（保留静态样式）
- 过场时间从 2.5s → 1.5s
- 情报弹窗增加 `setTimeout(() => closeIntel(), 2000)` 自动关闭
- `l1Answer` 中移除弹窗阻塞判断，答对/答错后统一 800ms 进入下一题
