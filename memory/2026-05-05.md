### 4. 数学 ch02 核心 Bug 修复
**Bug A: 分数比较显示 NaN/undefined**
- 根因: `genCompare()` 的 `mixed` 分支中，`c` 和 `d` 未定义就直接参与 `wholeA * c + ...` 计算
- 修复: 给 `mixed` 分支补上 `c = 2+random*6; d = 2+random*6`

**Bug B: "继续" 按钮无响应**
- 根因: 屏幕状态管理混乱
  - `restartGame()` 用内联样式 `style.display = 'flex'` 恢复 intro-screen
  - `nextLevel()` 只操作 CSS class 不碰内联样式，导致 intro-screen 可能一直悬在背景层遮挡新关卡
  - `nextLevel()` / `gameOver()` / `showResult()` 均未清理 `result-screen` 和 `level-clear-overlay`
- 修复:
  - `restartGame()`: 统一用 `classList`，先清所有 screen/overlay，再给 intro-screen 加 `active`
  - `nextLevel()`: 增加 `result-screen` 清理 + `clearInterval(timerInterval)`
  - `gameOver()` / `showResult()`: 增加 `clearInterval` + 全屏清理
- 提交: `e9f23a3d`
