### 严重错误

**错误1 — z-index 9999 扫描线遮挡**
- `body::before` z-index 9999 高于 `#app` (10)，页面全黑
- 修复: z-index → 5

**错误2 — 缺失 `</style>` 标签（最严重）**
- 用 `diff` 对比时误删 ch02 的"重复 CSS 块"，但这块实际上是 ch02 唯一的完整 CSS
- 连带删除了唯一的 `</style>` 闭合标签
- 浏览器把所有 HTML 当作 CSS 解析，页面完全无法渲染
- 修复: 补回 `</style>` + 恢复9个被误删的CSS类

**错误3 — 缺失 `</head>` 标签**
- 同上，误删时连带移除
- 修复: 补回 `</head>`

**错误4 — motionGraph canvas 黑块**
- ch3 canvas 无绘制代码
- 修复: 添加 IIFE 绘制匀速/变速 s-t 图像对比

### 教训
1. 不要盲目删除"重复"CSS — 先用脚本分析哪些类被使用但未被定义
2. edit 工具边界风险 — 复杂HTML编辑优先用 Python 脚本
3. 必须验证完整结构 — `</style>`、`</head>`、`<body>` 顺序
4. CDN 缓存欺骗 — 用时间戳绕过缓存才能获取真实线上状态

---

## 通用教训

- **编辑工具**: `edit` 适合小范围精确替换，大规模操作用 Python 脚本
- **QA验证**: 部署后必须等 CDN 刷新（用 `?ts=` 绕过缓存）
- **结构检查**: HTML 修复后必须验证标签闭合和嵌套顺序
- **视觉与答案**: 像素位置必须和文字答案一致
- **交互优于静态**: 答案用 opacity + transition 淡入，不要直接暴露
