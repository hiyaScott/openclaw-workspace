## 数学课件 "数的整除" — 知识讲解环节设计方案

### 目标
在现有4个游戏关卡前，加入"特工手册"教学环节。同样的HUD科幻风格，但内容是互动式知识讲解。

### 结构
```
开始画面
  ├─ 【学习模式】4个知识点卡片
  │    ├─ 卡片1: 整除的概念
  │    ├─ 卡片2: 2/3/5/9整除特征
  │    ├─ 卡片3: 质数与合数
  │    └─ 卡片4: GCD与LCM
  │         （每个卡片：概念动画→例题演示→小测试1-2题）
  │
  └─ 【挑战模式】直接进入现有4个关卡
```

### 卡片1: 整除的概念
- 动画：数字12被3个小人平分，每人4个，没有剩余（余数=0）
- 定义："a能被b整除" = a÷b = 整数，余数为0
- 例题：判断 15÷3, 17÷3, 24÷6
- 小测试：2道选择题

### 卡片2: 整除特征
- 2：个位是0/2/4/6/8 → 动画高亮个位
- 3：各位数字之和能被3整除 → 动画分解数字，求和
- 5：个位是0或5 → 动画高亮
- 9：各位数字之和能被9整除 → 动画分解
- 互动：给数字，让孩子点击符合的条件（多选）
- 小测试：3道判断题

### 卡片3: 质数与合数
- 定义动画：数字展开它的因数
  - 7 → [1, 7] → 只有2个 → 质数 ✅
  - 12 → [1, 2, 3, 4, 6, 12] → 多于2个 → 合数 ❌
  - 1 → [1] → 既不是质数也不是合数
- 100以内质数表：可点击的10×10数字矩阵，点击后质数变绿、合数变红、1变黄
- 小测试：4道判断题

### 卡片4: GCD与LCM
- GCD：辗转相除法动画演示（42和18）
  - 42÷18=2余6 → 18÷6=3余0 → GCD=6
  - 可视化：两个条形图，逐步切割
- LCM：公式法 LCM(a,b) = a×b÷GCD(a,b)
- 例题：求 GCD(36, 24) 和 LCM(4, 6)
- 小测试：2道填空题

### 技术实现
- 在现有HTML的 `<div id="app">` 前面加一个 `<div id="tutorial">`
- 教学和挑战模式在开始画面选择
- 同样的HUD风格：深色背景、霓虹色、扫描线
- 动画用CSS transitions + 少量Canvas
- 小测试用现有的按钮/反馈系统
- 所有代码内联，不依赖外部资源

### 输出
修改现有数学课件文件，在开头加入教学模式入口和4个知识点卡片。
