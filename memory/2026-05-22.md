## 物理 CH02 参照物实验 — 修正"运动/静止"平衡

**完成时间**: 2026-05-22 22:53
**Git提交**: `0489b900`

### 触发
Scott 2026-05-22 22:51 发截图指出互动实验中三个按钮结果全是"运动"，学生看不到"静止"状态。要求"应该有【静止】【运动】两种例子"。

### 修改内容

**1. Canvas 实验修正**
- 原逻辑：三辆车各自独立运动，无论选哪个参照物A都是运动
- 新逻辑：
  - 汽车B 与 A 保持固定距离差（同速并排行驶）
  - 选 **地面** → A 是 **运动**
  - 选 **汽车B（并排同速）** → A 是 **静止** ✅
  - 选 **汽车C（更快）** → A 是 **运动**（相对后退）

**2. 例题同步调整**
- 例题1：新增"同速时静止"场景，再讲"加速后运动"
- 例题2：三重参照物对比明确标出"电线杆→运动、C车→后退、并排小鸟→静止"
- 测验题Q2：从"甲看乙后退"改为"两列火车并排同速，甲看乙是静止的"

### 教训
- 互动实验不能只展示"运动"，必须同时展示"静止"才有教学价值
- "相对静止"概念需要通过可视化让学生直观感受（两物体并排同速时确实像"钉"在窗外）
- 例题设计要覆盖概念的两个极端状态（运动 vs 静止），不能只偏一端
