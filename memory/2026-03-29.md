### 问题解决记录

**1. 字幕乱码修复**
- 问题：使用 DejaVuSans 字体不支持中文，显示为方块
- 解决：改用 Noto Serif CJK 字体重新压制
- 工具：FFmpeg drawtext filter

**2. 临时BGM生成**
- 问题：海螺AI视频不带音频
- 解决：FFmpeg生成220Hz正弦波+淡入淡出
- 命令：`ffmpeg -f lavfi -i "sine=frequency=220:duration=18" -af "afade=t=in:ss=0:d=2,afade=t=out:st=15:d=3,volume=0.3"`

### 核心记忆固化

**AI短片制作标准流程**：
```
飞书指令 → Pipeline记录 → AI执行 → Web呈现 → 飞书确认
```

**5个标准Step**：
1. 剧本（飞书讨论）→ ¥0
2. 角色（即梦AI）→ Token消耗
3. 视频（海螺/可灵）→ API按次计费
4. 剪辑（FFmpeg）→ ¥0
5. 发布（GitHub Pages）→ ¥0

**4条铁律**：
1. 用户说"停"→立即停止
2. 遇到困难先问→不自己乱试
3. API调用前检查余额→最多3次重试
4. 每阶段完成必须用户确认→再进下一步
