### 技术改进

更新了 `pipeline.html` 的 `renderColumnContent` 函数：

```javascript
// 新增图片支持
if (column.image && !column.image.startsWith('[')) {
    // 显示实际图片
    html += `<img src="${column.image}" ...>`;
}

// 新增视频支持
if (column.videos && column.videos.length > 0) {
    column.videos.forEach(video => {
        html += `<video controls src="${video.src}">...</video>`;
    });
}
```

### 数据结构扩展

JSON数据文件新增字段：
- `image`: 图片路径（支持占位符 `[xxx]` 或实际路径 `./assets/...`）
- `imageCaption`: 图片说明文字
- `videos`: 视频列表数组，每项包含 `src`, `title`, `desc`
