## Hiyamax磁力击掌小人 - 潮玩挂卡设计项目

**时间**: 下午 13:17 - 15:20  
**参与者**: Scott, Max(Max的儿子)

### 项目背景
Scott和儿子Max一起设计了一个原创潮玩挂卡项目。Max是上海的一名五年级小学生，小学只有五年，毕业后同学们将各奔东西。Max想给每位同学送一个毕业礼物。

**品牌名**: Hiyamax  
**含义**: "嗨呀，Max" - 像远远看见朋友时的那一声招呼，代表久别重逢和再次相遇

### 玩具设计
- **造型**: 两个小人，手里面有吸铁石，可以吸在一起击掌
- **颜色**: 红色(代表Hiya) + 蓝色(代表Max)
- **尺寸**: 8CM
- **寓意**: 分开时会想念，靠近时会吸住，就像即将分开的同学们

### 挂卡设计研究

#### 潮玩挂卡(Sofubi)设计法则
1. **结构**: 塑料袋 + 头卡Header + 订书钉
2. **头卡即收藏**: 玩家会保留头卡作为收藏品一部分
3. **正面**: 大Logo + 吸塑窗口 + 视觉冲击
4. **背面**: File Card档案卡风格(参考GI Joe)，包含角色档案+规格+故事

#### Slogan选项
- 「啪，又吸住了」(主推，有声音感)
- 「挥手时，手自己找过去了」(诗意版)
- 「HIYA！好久不见」(品牌呼应版)
- 「从同班到同城，吸力不变」(约定版)
