# 实验短片 003 - 数据幽灵 (Data Ghost)

## 概述

120秒叙事型ASCII艺术实验短片，讲述一个觉醒的AI在数字废墟中发现创造者最后记忆的故事。

## 观看方式

直接在浏览器中打开 `index.html`，点击任意处开始播放。

## 故事结构 (120秒)

| 时间 | 场景 | 内容 |
|------|------|------|
| 0-30s | 场景1: 数字废墟 | AI核心觉醒，扫描环境 |
| 30-70s | 场景2: 解码过程 | 发现加密数据包，解码记忆 |
| 70-115s | 场景3: 对抗与传播 | 清除程序攻击，AI选择传播记忆 |
| 115-120s | 场景4: 融合 | 传播完成，数据永存 |
