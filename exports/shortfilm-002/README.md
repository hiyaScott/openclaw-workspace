# 实验短片 002 - ASCII ROBOT

## 概述

60秒交互式ASCII艺术实验短片，展示一个赛博朋克风格的机器人动画。

## 观看方式

1. 直接在浏览器中打开 `index.html` 文件
2. 点击页面任意位置开始播放
3. 建议佩戴耳机以获得最佳音频体验

## 短片结构

| 时间段 | 内容 | 音频 |
|--------|------|------|
| 0-5秒 | 片头：实验短片002标题卡 | 上升音阶音效 |
| 5-50秒 | 主体：ASCII机器人动画 + BGM | 赛博朋克风格循环音乐 + 机械音效 |
| 50-60秒 | 片尾：THE END / 完 / 感谢观看 | 下降音阶音效 |

## 技术特点

### 视觉
- 区块字符艺术 (Block ASCII)：使用 █ ▓ ▒ ░ 等字符
- 霓虹色彩主题：青色、洋红、黄色循环变化
- 扫描线效果 + 暗角 + 噪点纹理
- 8帧机器人动画循环

### 音频
- Web Audio API 实时生成
- 8和弦赛博朋克BGM序列
- 机械运动音效
- 扫描音效
- 片头片尾音效

### 交互
- 点击启动
- 空格键快捷启动
- 实时进度条
- 计时器显示
