# 实验短片004 - 声音的形状 (The Shape of Sound)
## 详细剧本与分镜

---

## 基本信息
- **片名**: 声音的形状 / The Shape of Sound
- **时长**: 120秒
- **风格**: 抽象表现主义 / ASCII粒子艺术 / 视听联觉
- **主题**: 失聪音乐家的跨维度对话

---

## 故事大纲
一位失聪的音乐家通过自己发明的可视化设备，将声音转化为视觉图案。某天，他接收到了一段来自未知维度的"声音"——这不是地球上的任何频率，而是另一个世界的求救信号。音乐家尝试用自己的音乐回应，最终两个世界在视觉与声音的融合中连接。

## 技术实现要点

### 1. 波形生成算法
- 使用正弦波叠加模拟真实声波
- 不同频率对应不同字符密度
- 振幅控制字符亮度/大小

### 2. 色彩映射
```
时间轴    0s      30s      60s      90s      120s
          │       │        │        │        │
颜色      白────→蓝────→青────→黄────→金
                  ↑        ↑        ↑
              发现    和谐    融合
```

### 3. 粒子系统
- 每个"声音粒子"是一个字符
- 粒子有位置、速度、生命周期
- 碰撞时产生新粒子（爆发效果）

### 4. 响应式交互
- 点击产生涟漪效果
- 鼠标移动影响局部波形
- 键盘空格键切换视角

---

## 音频设计 (Web Audio API)

### 音轨分层
1. **底层铺垫**: 60Hz正弦波，持续全片
2. **节奏层**: 发现信号后加入，BPM 72
3. **旋律层**: 和谐时刻出现，简单五声音阶
4. **噪声层**: 干扰时出现，代表外部威胁
5. **高潮层**: 多音轨和弦，最终融合

### 频率对应视觉
- C2 (65Hz): █ 低频块
- G2 (98Hz): ▓ 中低频
- C3 (131Hz): ● 中频圆
- E3 (165Hz): ○ 中高频
- G3 (196Hz): · 高频点

## 创新突破点

1. **首次ASCII音波可视化** - 用字符密度/类型表现频率

3. **双系统交互** - 两套视觉语言的对话与融合
4. **色彩叙事** - 冷暖色调的情感映射
