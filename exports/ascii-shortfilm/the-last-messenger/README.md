# 《最后的信使》(The Last Messenger)

一个由 **编剧知识 + ASCII Art 技术** 构建的完整动画短片。

---

## 📦 项目包含

| 文件 | 说明 |
|------|------|
| `SCRIPT.md` | 完整剧本（Save the Cat节拍表结构） |
| `the-last-messenger.html` | 可执行的ASCII动画播放器 |

---

## 🎬 故事简介

**时长**: 60秒  
**风格**: 末日科幻 / 诗意极简  
**主题**: 即使世界终结，信息仍需送达

一个机器人在末日废墟中醒来，肩负着传递最后一条信息的使命。它穿越荒原、攀登雪山，最终在信号塔顶将信息发送至星空。使命完成，它静静坐下，望向银河。

---

## 🎨 技术特点

### ASCII Art 设计
- **角色**: 机器人 R-07，简单几何形状，易于动画
- **场景**: 废墟城市、荒原、信号塔、星空
- **特效**: 雪花粒子、信号光束、星空闪烁

### 动画系统
- **帧率**: 12fps（复古感）
- **画布**: 80×40 字符网格
- **场景**: 6个场景，共60秒

### 6幕结构
| 时间 | 场景 | 内容 |
|------|------|------|
| 0-10s | 开场 | 机器人废墟中醒来 |
| 10-25s | 旅程 | 穿越荒原 |
| 25-35s | 中点 | 望见信号塔 |
| 35-45s | 危机 | 暴风雪中攀登 |
| 45-55s | 高潮 | 发送信息至星空 |
| 55-60s | 结局 | 使命完成，望向银河 |

---

## 📝 编剧技巧应用

### 三幕结构
- **第一幕** (0-12s): 建置，机器人醒来，接受任务
- **第二幕** (12-45s): 对抗，穿越荒原，克服暴风雪
- **第三幕** (45-60s): 解决，发送信息，完成使命

### Save the Cat 节拍
- ✅ 开场画面：废墟中的光点
- ✅ 催化剂：任务界面激活
- ✅ 中点：望见信号塔（虚假希望/挑战开始）
- ✅ 一无所有：电量不足，几乎放弃
- ✅ 结局画面：信息送达，望向星空

### 环境叙事
没有对白，通过场景变化讲故事：
- 沿途的机器人残骸 → 暗示这条路之前有人走过
- 从城市废墟 → 开阔荒原 → 山顶信号塔 → 星空
- 色彩从灰 → 冷 → 暖（信号光）

## 💡 设计理念

> "ASCII Art 的限制是创造力的催化剂。"

- **极简美学**: 用最少字符传达最大情感
- **留白的诗意**: 黑底 + 简单线条 = 想象空间
- **复古与未来的碰撞**: 80年代文字冒险游戏 × 末日科幻故事
