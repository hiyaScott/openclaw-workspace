## 二、喷头选型逻辑

### 输入参数
- `width`：区域宽度（米）
- `type`：植物类型（`shrub`灌木带 / `lawn`草坪 / `flower`花卉）
- `narrow_preference`：窄带偏好（`drip`滴灌管 / `micro_stake`地插微喷头）

### 选型规则

```
IF width < 1.0:
    IF type ∈ {shrub, flower}:
        返回 narrow_preference 对应的类型
        → drip 或 microStake

IF 1.0 ≤ width ≤ 1.5:
    IF type ∈ {shrub, flower} → rect78012
    IF type == lawn → rect78004

IF 1.5 < width ≤ 5.0:
    IF type ∈ {shrub, flower} → fan78012
    IF type == lawn → fan78004

IF 5.0 ≤ width < 9.0:
    IF type ∈ {shrub, flower} → mini13012
    IF type == lawn → mini13003

IF 9.0 ≤ width ≤ 30.0 AND type == lawn:
    → super10003

IF 无匹配 → 返回 null（不布置喷头）
```

### 选型速查表

| 区域宽度 | 灌木带/花卉 | 草坪 |
|---------|------------|------|
| < 1m | 滴灌管 / 地插微喷头 | 滴灌管 / 地插微喷头 |
| 1.0–1.5m | PRO-s-78012-矩形 | PRO-s-78004-矩形 |
| 1.5–5.0m | PRO-s-78012-扇形 | PRO-s-78004-扇形 |
| 5.0–9.0m | MiniPRO13012 | MiniPRO13003 |
| 9.0–30.0m | — | SuperPRO10003 |

## 三、喷头数量计算逻辑

### 输入
- `length`：区域长度（米）
- `width`：区域宽度（米）
- `type`：植物类型
- `sprinklerType`：选定的喷头类型
- `location`：布置位置（`edge`边上 / `center`中间）

### 各型号数量算法

#### 1. 滴灌管（`drip`）
```
行数 rows = ceil(width / 0.3)
数量 = length × rows
返回 { count: 数量, rows: rows }
```
- 行距 0.3m，沿长度方向铺设

#### 2. 地插微喷头（`microStake`）
```
数量 = ceil(length / 0.6)
返回 { count: 数量, rows: 1 }
```
- 间距 0.6m，沿中线单排布置

#### 3. 矩形喷头（`rect78012` / `rect78004`）
```
数量 = ceil(length / 3)
返回 { count: 数量, rows: 1 }
```
- 间距 3m，居中单行

#### 4. 扇形喷头（`fan78012` / `fan78004`）
```
rows = 1
IF width > 3.0:
    rows = location == "center" ? 2 : 1
IF width >= 6.0 AND width <= 9.0:
    rows = 2

spacing = width
每行数量 = ceil(length / spacing)
总数量 = 每行数量 × rows

返回 { count: 总数量, rows: rows }
```

#### 5. MiniPRO（`mini13012` / `mini13003`）
```
rows = 2
spacing = width
每行数量 = ceil(length / spacing)
总数量 = 每行数量 × rows

返回 { count: 总数量, rows: rows }
```

#### 6. SuperPRO（`super10003`）
```
数量 = ceil(length / 10 + 1) × ceil(width / 10 + 1)
返回 { count: 数量, rows: 1 }
```
- 10m 间距网格布置

## 五、电磁阀选型逻辑

### 5.1 型号选择
```
IF pipeSize == 25mm → K-rain 7075型
IF pipeSize == 32mm 或 river_well → K-rain 7001型
```

### 5.2 单价
```
7075型(25mm): 材料¥180 + 安装¥115 = ¥295/个
7001型(32mm): 材料¥196 + 安装¥115 = ¥311/个
```

### 5.3 数量计算

**核心逻辑：按喷头类型分组，每组流量不超过水源流量**

```
// Step 1: 按喷头类型分组统计
sprinklerGroups = {}  // key=喷头类型, value={count, flow, spacing}

FOR EACH 区域:
    FOR EACH 喷头型号:
        该组流量 += 喷头数量 × 单喷头流量

// Step 2: 计算各组所需阀门数
valveCount = 0
FOR EACH 喷头组:
    groupValves = ceil(该组流量 / waterFlow)
    valveCount += groupValves

// Step 3: 保底
valveCount = max(1, valveCount)
```

**注**：不同喷头类型必须分不同阀门组，因为流量特性不同。

## 七、管路选型逻辑

### 7.1 主管（PPR管）

**管径选择：**
```
IF pipeSize == 32mm 或 isRiverWell:
    mainPipeSize = 32
ELSE:
    // 自来水25mm
    IF valveCount >= 5:
        mainPipeSize = 32
    ELSE:
        mainPipeSize = 25
```

**长度：**
```
mainPipeLength = gardenPerimeter（花园周长）
```

**单价：**
```
32管: ¥13材料 + ¥8.5安装 = ¥21.5/米
25管: ¥9材料 + ¥8.5安装 = ¥17.5/米
```

### 7.2 支管（PPR 25管）

**长度：**
```
FOR EACH 喷头组:
    IF 该组有spacing且spacing > 0:
        branchPipeLength += 喷头数量 × spacing
```

**单价：**
```
25管: ¥9材料 + ¥8.5安装 = ¥17.5/米
```

### 7.3 20mm PE支管（地插微喷头专用）

```
microStakePipeLength = 所有使用microStake的区域的length之和
单价: ¥2.5材料 + ¥1.5安装 = ¥4/米
```

## 十一、总报价计算公式

```
totalCost = 
    sprinklerCost          // 喷头材料费
    + installFee            // 喷头安装费
    + qianqiuCost           // 千秋架
    + valveCost             // 电磁阀
    + valveBoxCost          // 阀门箱
    + controllerCost        // 控制器
    + decoderCost           // 解码器（如有）
    + rainSensorCost        // 雨感器
    + mainPipeCost          // 主管
    + branchPipeCost        // 支管
    + microStakePipeCost    // PE支管（如有）
    + fittingCost           // PPR管件
    + controlLineCost       // 控制线
    + conduitCost           // 穿线管
    + pumpCost              // 增压泵（自来水）
    + riverWellCost         // 河水设备（河水）
    + excavationCost        // 土方开挖
    + backfillCost          // 土方回填
    + dripFittingCost       // 滴灌管件（如有）
```

## 十二、CAD系统复现要点

### 需要保留的规则

1. **喷头选型**：宽度阈值（1m / 1.5m / 5m / 9m / 30m）必须一致
2. **喷头数量**：各型号的间距算法必须一致
3. **阀门分组**：按喷头类型分组的逻辑必须一致
4. **管径选择**：valveCount ≥ 5 时主管升级到32mm
5. **控制器升级**：阀门 > 12 时切换为 PROEX-3.0 + 解码器

### 需要空间化的规则

1. **喷头位置**：从"矩形长宽"扩展到"多边形内的坐标"
2. **管路走向**：从"估算长度"变为"实际几何路径"
3. **区域边界**：从"长宽输入"变为"多边形绘制"

### 可以简化的规则

1. **土方量**：CAD系统可先输出管长，土方按管长×单价自动算
2. **报价**：CAD系统输出材料清单，报价由现有计算器承接
