## 解决方案

### 方案1: 用户转换（最快）
用户用AutoCAD/中望CAD打开DWG，另存为DXF格式(R2000或R2018)，
然后发给我DXF文件。我可以立即解析DXF（已有纯Python解析器）。

### 方案2: 等待工具安装
等服务器网络恢复后，安装ezdxf：
```bash
pip install ezdxf
```
ezdxf会自动调用ODAFileConverter进行DWG→DXF转换，然后解析。

### 方案3: 前端直接读取
如果用户有AutoCAD，可以直接复制图纸中的区域边界坐标，
贴到我前端Canvas里，手动绘制区域后自动生成方案。
